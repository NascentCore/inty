# 同步角色主题专区 Dev 到 Prod

<!-- CREATED_BY_AGENT -->

从 dev 环境同步角色主题专区数据到 prod 环境。

## 功能特性

- 自动同步 dev 环境中的所有角色主题专区到 prod 环境
- 支持创建、更新和删除操作
- 自动同步主题与角色的关联关系
- 智能处理可见性唯一性约束（PRIMARY/SECONDARY）
- 自动跳过 prod 中不存在的角色关联
- Dry-run 模式预览更改
- 详细的日志记录

## 同步逻辑

同步操作按以下顺序执行：

1. **删除**: prod 存在但 dev 不存在的主题专区
2. **更新**: dev 和 prod 都存在但字段不同的主题专区
3. **创建**: dev 存在但 prod 不存在的主题专区

### 关联角色同步

- 对于每个同步的主题，会同步其关联的角色列表
- 如果 dev 中关联的角色在 prod 中不存在，会记录警告并跳过该关联
- 角色顺序（order_index）会保持一致

### 可见性唯一性约束

- PRIMARY 和 SECONDARY 可见性具有唯一性约束（同一时间只能有一个）
- 同步时会自动将 prod 中冲突的主题设为 HIDDEN

## 配置

复制配置文件示例并修改数据库连接信息：

```bash

```

编辑 config.yaml 文件，配置：

- 日志级别

## 命令行参数

- `--config <path>`: 指定配置文件路径（默认: config.yaml）
- `--dry-run`: 预览模式，不实际执行操作

## 注意事项

1. **角色依赖**: 主题关联的角色必须先同步到 prod 环境，否则关联会被跳过
2. **可见性冲突**: 同步时会自动处理 PRIMARY/SECONDARY 可见性冲突
3. **物理删除**: 删除操作是物理删除，会删除主题及其所有关联记录
4. **事务安全**: 所有操作在一个事务中执行，如有错误会自动回滚
5. **建议流程**:
   - 先运行角色同步脚本（sync_agents_dev_to_prod）
   - 再运行主题专区同步脚本
   - 先运行 dry-run 预览，确认无误后再执行实际同步

## 故障排除

### 数据库连接失败

检查配置文件中的数据库连接信息是否正确，确认数据库服务正在运行。

### 角色关联被跳过

如果看到"跳过角色关联"的警告，说明 dev 中关联的角色在 prod 中不存在。请先运行角色同步脚本。

### Alembic 版本不一致

确保 dev 和 prod 数据库的 schema 版本一致，使用 `alembic current` 检查版本。

### 同步失败

查看详细日志输出，检查具体错误信息。所有失败的操作会自动回滚，不会影响数据一致性。

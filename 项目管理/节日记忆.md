## 待测试用例

以下用例用于手测或自动化验收，与 [tests/docs/TEST_PLAN_FESTIVAL_MEMORY_PUSH.md](tests/docs/TEST_PLAN_FESTIVAL_MEMORY_PUSH.md) 对齐。

### 一、后端 API 与版本门控

| 用例 | 步骤 | 预期 |
|------|------|------|
| GET 消息列表 - 版本满足 | 请求 `GET /api/v1/chats/agents/{agent_id}/messages`，Header `appVersionCode` ≥ config 中 `min_app_version_code_for_festival_memory` | 响应中可包含 `type === "festival_memory_prompt"` 的消息 |
| GET 消息列表 - 版本不满足 | 同上，`appVersionCode` < 配置值 | 响应中不包含 `festival_memory_prompt` 类型消息（仅过滤，total 可能仍含被隐藏条数） |
| GET 角色详情 - 版本满足 | 请求 `GET /api/v1/ai/agents/{agent_id}`，`appVersionCode` ≥ 配置值 | 响应含 `features.festival_memories`（有则非空） |
| GET 角色详情 - 版本不满足 | 同上，`appVersionCode` < 配置值 | 不返回 `features.festival_memories` 或为空 |
| POST 聊天补全 - 版本满足 | 请求 `POST /api/v1/chat/completions/{agent_id}`，`appVersionCode` ≥ 配置值，该用户该角色有未投递节日记忆 | 响应 choices 中可包含 `festival_memory_prompt` 类型条目 |
| POST 聊天补全 - 版本不满足 | 同上，`appVersionCode` < 配置值 | 响应 choices 中不包含 `festival_memory_prompt` |
| 版本未传 | 上述任一接口不传 `appVersionCode` | 按「不限制」处理，照常返回节日记忆相关数据 |

说明：单测/集成测见 `tests/app/api/`、`tests/app/services/`（如 `test_festival_memory_chat_history_e2e.py`、`test_chat.py` 中 version gating、`test_memory_service_deliver_festival_integration.py`）。

### 二、Android - 节日记忆推送点击

| 用例 | 步骤 | 预期 |
|------|------|------|
| 通知展示 | 收到 payload 含 `type: "festival_memory"`、`agent_id`（及可选 `festival_memory_id`）的 FCM 推送 | 通知栏展示服务端下发的 title/body |
| 点击跳转 - 前台/后台 | 应用在前台或后台时点击该通知 | 进入该角色 **Love Journal** 页；若带 `festival_memory_id` 则定位到对应记忆条 |
| 点击跳转 - 冷启动 | 应用未运行，从该通知点击启动 | MainActivity 根据 type、agent_id、festival_memory_id 打开 Love Journal 并定位到对应记忆 |
| 边界 - 缺 agent_id | 推送或模拟 Intent 仅带 `type=festival_memory`，无 agent_id | 不崩溃，跳转主页面 |
| 边界 - 缺 festival_memory_id | 仅带 type + agent_id | 仅打开该角色 Love Journal 列表，不定位到单条 |

**ADB 模拟点击（不依赖真实 FCM）**：用于快速验证「点击后跳转」逻辑。

```bash
# 仅打开该角色 Love Journal（不定位某条）
adb shell am start -n com.ai.intellimate/.MainActivity \
  --es type festival_memory --es agent_id "<agent_id>"

# 打开并定位到某条记忆（memory_id 为 memory 表主键）
adb shell am start -n com.ai.intellimate/.MainActivity \
  --es type festival_memory --es agent_id "<agent_id>" \
  --el festival_memory_id <memory_id>

# 冷启动场景：先杀进程再执行上述 start 命令
adb shell am force-stop com.ai.intellimate
```

### 三、Android - 记忆拉取与展示

| 用例 | 步骤 | 预期 |
|------|------|------|
| 进聊天页拉取记忆 | 进入某角色聊天页 | 调用 GET agent（或 refreshAgent），本地写入该角色 festival_memories；聊天内若有未投递节日记忆会收到 festival_memory_prompt |
| 进 Love Journal 拉取记忆 | 从聊天更多面板或推送进入该角色 Love Journal | Heartbeat 页加载时 refreshAgent，列表展示该角色节日记忆；从推送进入时本地可能无缓存，依赖此次刷新 |

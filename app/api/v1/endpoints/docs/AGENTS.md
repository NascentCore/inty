# `app/api/v1/endpoints/docs/`：端点的人类可读说明

**一句话**：每个 Markdown 文件 **对应父目录里的一个 `*.py` 路由模块**，用散文补充 **OpenAPI 表达不清的语义与边界**。

## 写作与验证习惯

- **对照源码**：文档叙述必须与 **当前 handler 行为** 一致；漂移时优先改代码或改文档，不要留第三真相。
- **验库读库**：若示例涉及数据库断言，请用 **新会话** 读取，避免 ORM 会话缓存误判。
- **本地 URL**：示例默认后端在 **`http://localhost:8000`**；Ops 端口不同时自行替换。

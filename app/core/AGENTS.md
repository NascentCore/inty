# `app/core/`：领域核心能力

**一句话**：这里是 **离「智能体如何思考与行动」最近的后端核心**——模型调用、记忆、多模态与伴侣编排等 **重逻辑** 优先落在此树，而不是散落在 API 薄层。

## 适用读者

- 修改 companion 推理环、记忆、工具、语音/图像内核或相关配置的工程师与编码智能体。

## 心智模型

- **与 `app/api` 的分工**：API 层做鉴权、DTO 与事务边界；**core** 承载可复用的领域行为与昂贵计算。
- **稳定性预期**：子目录各有 AGENTS 说明；**companion_harness** 仍在快速演进，允许为产品目标调整内部契约。

# Agentic Kernel aka. iMate backend agentic core

- **Tool loop finish + LangSmith**: After tools finish, the model must emit routing JSON (`output_to_user`, `user_visible_text`) in **`message.content`** per [`/app/core/agentic_kernel/companion/prompts/system_messages.py`](/app/core/agentic_kernel/companion/prompts/system_messages.py); [`tool_bg_routing.py`](/app/core/agentic_kernel/companion/tool_bg_routing.py) parses it and otherwise runs **one extra** no-tools completion, so traces often show a final "structured" round that is **routing**, not another tool call, and some providers put that JSON only under **`reasoning` / `reasoning_details`** while **`content`** stays null or plain prose until the dual-channel reader TODO in [`tool_background.py`](/app/core/agentic_kernel/companion/tool_background.py) is addressed.

# 用户信息显示功能

## 功能概述

在所有页面右上角显示当前使用 API Key 获得的用户信息，包括用户头像、昵称、邮箱和管理员状态。

## 功能特性

### 1. 用户信息显示
- **头像**: 显示用户头像，如果没有则显示默认用户图标
- **昵称**: 显示用户昵称或用户ID
- **邮箱**: 显示用户邮箱地址
- **管理员标识**: 如果是管理员用户，会显示"管理员"标识

### 2. 交互功能
- **下拉菜单**: 点击用户信息区域可展开下拉菜单
- **详细信息**: 菜单中显示完整的用户信息
- **API Key 管理**: 在菜单中显示 API Key 状态和设置选项
- **清除 API Key**: 提供快速清除 API Key 的选项

### 3. 状态管理
- **自动加载**: 当 API Key 设置成功后自动获取用户信息
- **实时更新**: API Key 状态变化时自动更新用户信息
- **错误处理**: 获取用户信息失败时优雅降级
- **强制设置**: 没有 API Key 时模态框无法关闭，确保用户必须设置

## 技术实现

### 组件结构
```
UserInfo
├── 用户头像 (Avatar)
├── 用户信息 (昵称/ID + 角色)
└── 下拉菜单 (Dropdown)
    ├── 详细信息展示
    ├── API Key 状态显示
    ├── 设置/重新设置 API Key
    └── 清除 API Key 选项
```

### API 调用
- 使用 `/api/v1/users/profile` 端点获取用户信息
- 通过 Inty SDK 的 `api.v1.users.profile.retrieve()` 方法调用
- 自动处理 API Key 验证和错误处理

### 状态管理
- 使用 React Context 管理 API Key 状态
- 通过 `useApiKeyContext` 获取 API Key 验证状态
- 使用 `useCallback` 优化性能，避免不必要的重新渲染

## 使用方式

### 1. 设置 API Key
1. 点击右上角用户信息区域
2. 在下拉菜单中选择"设置 API Key"或"重新设置 API Key"
3. 输入有效的 API Key
4. 系统自动验证并获取用户信息

**注意**: 如果没有设置 API Key，模态框将无法关闭，用户必须输入有效的 API Key 才能继续使用系统。

### 2. 查看用户信息
1. 在页面右上角查看用户头像和基本信息
2. 点击用户信息区域查看详细信息
3. 在下拉菜单中查看完整用户资料

### 3. 清除 API Key
1. 点击右上角用户信息区域展开下拉菜单
2. 选择"清除 API Key"选项
3. 系统清除 API Key 并重置用户信息

## 页面布局

用户信息组件位于所有页面的右上角，具体位置：
- **水平位置**: 页面头部右侧
- **垂直位置**: 与页面标题同一行
- **响应式**: 在不同屏幕尺寸下自适应显示

## 错误处理

### 常见错误情况
1. **API Key 无效**: 不显示用户信息组件
2. **网络错误**: 显示加载状态，重试获取
3. **用户信息获取失败**: 优雅降级，不显示组件

### 错误恢复
- 自动重试机制
- 用户友好的错误提示
- 优雅的降级处理

## 注意事项

1. **权限要求**: 需要有效的 API Key 才能显示用户信息
2. **数据安全**: 用户信息仅在本地显示，不会存储到本地存储
3. **性能优化**: 使用缓存机制避免重复请求
4. **响应式设计**: 在不同设备上都能正常显示

# 用户信息显示功能

## 功能概述

在所有页面右上角显示当前使用 API Key 获得的用户信息，包括用户头像、昵称、邮箱和管理员状态。

### 用户信息显示

- **头像**: 显示用户头像，如果没有则显示默认用户图标
- **昵称**: 显示用户昵称或用户ID
- **邮箱**: 显示用户邮箱地址
- **管理员标识**: 如果是管理员用户，会显示"管理员"标识

## 使用方式

### 1. 设置 API Key

1. 点击右上角用户信息区域
2. 在下拉菜单中选择"设置 API Key"或"重新设置 API Key"
3. 输入有效的 API Key
4. 系统自动验证并获取用户信息

<img width="960" height="1574" alt="image" src="https://github.com/user-attachments/assets/f836672a-2c54-4382-9ef5-fe5f68db3a6b" />

**注意**: 如果没有设置 API Key，模态框将无法关闭，用户必须输入有效的 API Key 才能继续使用系统。

### 2. 查看用户信息

1. 在页面右上角查看用户头像和基本信息
2. 点击用户信息区域查看详细信息
3. 在下拉菜单中查看完整用户资料

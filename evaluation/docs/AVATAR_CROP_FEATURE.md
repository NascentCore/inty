# 头像截取功能使用说明

## 功能概述

在智能体管理页面的编辑模式中，支持上传图片后手动截取正方形头像区域，截取后的图片将显示为圆形头像。创建智能体时直接上传图片作为头像，不进行截取。

## 使用方法

### 1. 创建智能体时上传头像

1. 进入"智能体管理"页面
2. 点击"新建智能体"按钮
3. 在"形象"字段中点击上传区域
4. 选择一张图片文件
5. 图片直接作为智能体头像，无需截取

### 2. 编辑智能体时更换头像（支持截取）

1. 在智能体列表中点击"编辑"按钮
2. 在"形象"字段中重新上传图片
3. 系统会自动打开图片截取模态框
4. 拖拽调整截取区域（默认为正方形）
5. 点击"确认截取"完成头像设置

## 功能特点

- **正方形截取**：确保头像比例一致
- **圆形显示**：截取的正方形图片在界面上显示为圆形
- **实时预览**：截取过程中可以实时看到圆形预览效果
- **拖拽调整**：支持拖拽调整截取区域位置和大小
- **重置功能**：可以重置截取区域到默认位置

## 技术实现

- 使用 `react-image-crop` 库实现图片截取功能
- 支持 1:1 正方形比例截取
- 自动生成圆形预览效果
- 截取后的图片自动转换为 JPEG 格式

## 注意事项

- 建议上传清晰度较高的图片以获得更好的截取效果
- 截取区域最小尺寸为 50x50 像素
- 支持常见图片格式：JPG、PNG、GIF 等
- 截取后的图片会自动压缩以优化上传速度

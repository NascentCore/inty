# API 按键使用指南

## 概述

InTy体育系统需要API密钥才能正常使用。API密钥是用于身份验证的密钥，确保只有授权用户才能访问系统功能。

## API 钥匙

### 首次访问

首次访问系统时，会自动弹出API按钮设置对话框。

### 设置步骤

1. 在对话框中输入您的 API 键
2.点击“确认”按钮
3. 系统验证 API 按键有效
4.验证成功后即可正常使用

### 状态显示

- 红色"设置API Key" - 未设置或无效
- 绿色"API Key 已设置" - 有效且已保存

## 管理 API 钥匙

###重新设置

1.点击侧边栏“设置API Key”按钮
2.输入新的API键
3.点击“确认”验证
4.新的API键替换旧的

###清除API钥匙

1.确保状态为“已设置”
2.点击“清除API键”按钮
3.确认清除操作
4.系统清除数据并提示重新设置

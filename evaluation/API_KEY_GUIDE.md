# API Key 使用指南

## 概述

InTy 评测系统需要 API Key 才能正常使用。API Key 是用于身份验证的密钥，确保只有授权用户才能访问系统功能。

## 设置 API Key

### 首次访问

首次访问系统时，会自动弹出 API Key 设置对话框。

### 设置步骤

1. 在对话框中输入您的 API Key
2. 点击"确认"按钮
3. 系统验证 API Key 有效性
4. 验证成功后即可正常使用

### 状态显示

- 红色"设置 API Key" - 未设置或无效
- 绿色"API Key 已设置" - 有效且已保存

## 管理 API Key

### 重新设置

1. 点击侧边栏"设置 API Key"按钮
2. 输入新的 API Key
3. 点击"确认"验证
4. 新 API Key 替换旧的

### 清除 API Key

1. 确保状态为"已设置"
2. 点击"清除 API Key"按钮
3. 确认清除操作
4. 系统清除数据并提示重新设置

## 常见问题

### 如何获取 API Key？

联系 @亚雄 获取 API Key。

### API Key 丢失了怎么办？

联系管理员重新生成。系统无法显示已保存的 API Key。

---

**注意**: 请妥善保管您的 API Key，不要与他人分享。如怀疑泄露，请立即联系管理员重新生成。

# API Key 使用指南

## 概述

InTy 评测系统需要 API Key 才能正常使用。API Key 是用于身份验证的密钥，确保只有授权用户才能访问系统功能。

## 设置 API Key

### 首次访问

首次访问系统时，会自动弹出 API Key 设置对话框。

### 设置步骤

1. 在对话框中输入您的 API Key
2. 点击"确认"按钮
3. 系统验证 API Key 有效性
4. 验证成功后即可正常使用

### 状态显示

- 红色"设置 API Key" - 未设置或无效
- 绿色"API Key 已设置" - 有效且已保存

## 管理 API Key

### 重新设置

1. 点击侧边栏"设置 API Key"按钮
2. 输入新的 API Key
3. 点击"确认"验证
4. 新 API Key 替换旧的

### 清除 API Key

1. 确保状态为"已设置"
2. 点击"清除 API Key"按钮
3. 确认清除操作
4. 系统清除数据并提示重新设置

## 常见问题

### 如何获取 API Key？

联系系统管理员获取 API Key。

### API Key 丢失了怎么办？

联系管理员重新生成。系统无法显示已保存的 API Key。

### 为什么清除后无法使用系统？

这是安全机制。清除后需要重新设置有效的 API Key 才能继续使用。

### API Key 会过期吗？

浏览器中保存的 API Key 会在 30 天后自动清除，需要重新设置。

### 可以在多个设备使用吗？

可以，同一 API Key 可在多个设备使用，每个设备独立保存。

## 故障排除

### 验证失败

检查：
1. API Key 是否正确（无多余空格）
2. 网络连接是否正常
3. API Key 是否有效

### 清除后无法重新设置

1. 刷新浏览器页面
2. 清除浏览器缓存和 Cookie
3. 重新访问系统

### 系统提示"API Key 未设置"

1. 检查浏览器是否禁用 Cookie
2. 尝试隐私模式访问
3. 联系技术支持

---

**注意**: 请妥善保管您的 API Key，不要与他人分享。如怀疑泄露，请立即联系管理员重新生成。

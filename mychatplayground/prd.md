## Mychatplayground

### 项目概述
一个基于 OpenRouter 的提示词开发与调试工具集，包含多个独立功能模块，通过顶部导航栏切换。

---

## 模块一：聊天提示词（角色扮演/聊天）

### 目标
- 在同一界面完成提示词编辑与聊天验证，快速迭代提示词效果。

### 界面与流程
- 布局：左侧为提示词编辑区，右侧为聊天窗口。
- 提示词编辑区：只存放初始提示词（系统/角色设定/示例对话可选），编辑后新的对话请求使用最新提示词。
- 聊天窗口：右侧显示上下文对话记录与模型回复；支持连续多轮。
- 不需要会话切换；仅提供一键重置聊天窗口。

### 模型请求与调试
- 可选模型与基础参数（temperature、top_p、max_tokens、presence_penalty等）。
- 查看请求/响应原始 payload（含提示词与参数），便于调试截断/注入问题。
- 暂不支持提示对比（A/B）。

### 提示版本管理
- 快照/版本：保存当前提示词为一个命名版本；可回滚应用某版本。
- 简单 diff：展示当前编辑内容与上一个保存版本的差异（文本 diff）。

### 数据与日志
- 本地存储（localStorage/IndexedDB）保存：当前提示词、版本列表、聊天记录、参数。
- 导出/导入：JSON 含提示词、版本列表、聊天记录、参数，便于分享/备份。

### 便捷功能
- 预设模板：常用角色模板列表，一键套用到提示词编辑区。
- 变量插值：支持占位符（如 {{user_name}}），发送前进行替换。
- 截断提醒：提示词+历史长度接近模型上限时提醒。

### 基础非功能
- 错误与超时提示、重试。
- UI 快捷键：发送（Cmd+Enter）、保存提示版本、应用版本。

## 模块二：图片提示词生成器

### 目标
- 将用户输入的中文/简单描述，转换为适合 AI 生图工具（Stable Diffusion、Midjourney、DALL-E 等）使用的英文提示词。
- 支持双分支对比，同时测试不同模型/提示词配置的效果。

### 界面布局（三栏）
```
┌──────────┬─────────────────────────────────┬─────────────────────────────────┐
│          │         分支 A                   │         分支 B                   │
│  输入区   ├─────────────────────────────────┼─────────────────────────────────┤
│          │  模型选择 │ 系统提示词编辑         │  模型选择 │ 系统提示词编辑         │
│  用户描述 ├─────────────────────────────────┼─────────────────────────────────┤
│          │         输出结果 A               │         输出结果 B               │
│  [生成]   │         (一键复制)               │         (一键复制)               │
└──────────┴─────────────────────────────────┴─────────────────────────────────┘
```

### 界面与流程
- 独立页面，通过顶部导航栏访问。
- 左侧：输入区，用户填写原始描述（支持中文）。
- 中间 + 右侧：两条并行分支（分支 A 和分支 B），每个分支包含：
  - 模型选择下拉框
  - 系统提示词编辑区（可自定义转换规则）
  - 输出结果展示区（支持一键复制）
- 点击「生成」按钮后，两个分支同时发起请求，分别展示结果。
- 重新输入后点击生成，不保留之前的输出记录。

### 功能特性
- 双分支对比：可同时测试不同模型或不同提示词的效果。
- 系统提示词可编辑：用户可自定义转换规则和风格。
- 模型独立选择：每个分支可选择不同模型。
- 快捷操作：Cmd+Enter 生成、一键复制结果。

### 数据存储
- 与主功能共享 OpenRouter API Key。
- 独立存储：每个分支的模型选择、系统提示词配置。
- 不保留历史记录（每次生成覆盖上一次结果）。

## 通用架构

### 导航
- 顶部固定导航栏，支持在不同功能模块间切换。
- 当前页面高亮显示。

### 共享组件
- API Key 配置（localStorage 共享）。
- OpenRouter API 调用封装。

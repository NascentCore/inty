## New features

- 用户一行输入 → 前台 `chat` 回复（metadata section：`chat` + `user_msg_uuid` / LangSmith ids）。
- 连接后隐式 `greeting`（`user_signed_on` 问候轮）。
- **inner-tick**：`proactive-chat`、`maintenance`、`scheduled-reminder`；可无正文 `[SILENT]`。
- **tool background**：`toolcall` 补帧；`tool_background_started=true`；可选 `image-url:`、`local-path:`。
- `transcript-compaction:` 单行（长上下文截窗时）。
- **Experience profile**：`bootstrap` 阶段与 `post_bootstrap`（如 `intimate`）；bootstrap 工具 `companion_update_prompt_slice`、`companion_bootstrap_user_interactive_complete`、`companion_set_experience_profile`。
- 对话可触发工具：MemoryStore 读写、`google_web_search`、`read_web_page`、`generate_image` / `modify_image`、`living_sphere_record_update`、`techno_core_record_event`、`schedule_task`、`user_profile_record`、`companion_runtime_inspect`、`phone_call_user`（环境未配则可能失败）。
- WebSocket 重连：stderr `websocket connected` / `connection lost` / `restored`。

## Changed features

None

## Expected results in REPL

- 发消息后：先 `user-input message-uuid=…`，再 `[墙钟] chat <ms>ms` 与正文；可选 `langsmith_*_url=`。
- 签入后：可能出现 `[墙钟] greeting …` 问候正文（无用户输入行）。
- 等待 inner-tick：`inner-tick proactive-chat` 或 `maintenance` 或 `scheduled-reminder`；仅 `[SILENT]` 时无第二行正文。
- 工具后台：`chat` 行带 `tool_background_started=true` 后，可出现 `toolcall` 行；生成图见 `image-url:`，本地路径见 `local-path:`。
- 压实：assistant 后出现 `transcript-compaction: reason=… chars_before=…`。
- bootstrap：多轮对话后 `context_mode` 可从 bootstrap 切到 settled profile（需多轮或 inspect MemoryStore）；完成工具后行为档位变化。
- 触发 `schedule_task` 后到期：见 `inner-tick scheduled-reminder`（可能 `[SILENT]` 或可见回复）。
- 断网重连：stderr 运输提示，重连后可继续 `>` 输入。

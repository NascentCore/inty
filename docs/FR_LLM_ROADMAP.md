# FR LLM 路线图（6 个月）
CREATED_BY_AGENT: gpt-5.2-codex-high

## 目标
- 在 6 个月内完成 LLM 能力的体系化升级，支持快速接入新模型并可运营、可评测、可降级。

## 原则
- **可替换**：模型接入统一接口，业务侧不耦合厂商。
- **可评测**：离线评测 + 小流量灰度 + 线上监控闭环。
- **可运营**：模型白名单、优先级、灰度与回退策略可配置。
- **可控成本**：分层模型池、预算与配额、任务降级与缓存。

## 路线图
### M1（0-2 个月）：模型平台底座
- 统一模型抽象层（对话/工具调用/流式响应/多模态入口）。
- 模型路由与降级机制（白名单、优先级、回退策略）。
- 观测指标与评测框架（质量、延迟、成本、失败率）。

### M2（2-4 个月）：多模态扩展
- 文生图链路稳定与质量评测完善。
- **文生视频模型接入**：建立异步任务编排、媒体处理与分发、审核与降级策略。
- 建立文生视频评测集与灰度验证流程。
- **文生音乐模型接入**：完善音频生成链路、存储分发、审核与降级策略。
- 建立文生音乐评测集与灰度验证流程。

### M3（4-6 个月）：产品化与运营
- Frontier 模型池与订阅权益联动。
- 文生视频与对话/剧情编排联动，形成关键情节插片体验。
- 模型升级公告与运营节奏，形成稳定可持续的迭代闭环。

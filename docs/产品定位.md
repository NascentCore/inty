产品定位
- 核心定位：智能助手 + 亲密伴侣，满足功能效率与情感陪伴的双重需求
- 差异化策略：避开竞品的"低幼化""玩具化"赛道，垂直深耕北美35岁+成熟人群
- 核心优势：高情商、懂生活、成年人视角的深度情感连接

目标用户
- 人群：北美35岁+成熟男性和女性
- 特征：高付费能力、稳定职业、深度情感空虚
- 需求本质：伴侣而非玩具——渴望长期关系、深度理解、持续记忆
- 数据验证：高活跃用户日均1000+对话轮次，平均使用时长30+分钟

核心功能
- 深度情感记忆：长短期记忆融合，记住用户喜好与经历，形成持续情感纽带
- 高保真沉浸体验：视觉大模型 + 语音克隆，视听一体的多模态交互
- 智能体生态：系统自动推送角色智能体，用户可付费创建专属智能体
- 主动交互（前瞻）："AI有心跳"，主动发起对话，模拟真实IM全双工体验
  - 关键认知（待验证）：深度交互质量 > 主动交互形式
  - 真正的情感连接来自对话深度，用户因深度交流主动回来，而非AI主动"撩"
  - 主动交互应定位为"关心型触达"（基于记忆关心用户重要事项），而非"撩拨型互动"
  - 核心问题：若产品已建立深度情感连接，用户会主动回来——主动交互的价值是什么？
    - 生活提醒：基于记忆关心用户重要事项
    - 情感陪伴：察觉用户连续多日未登录
    - 内容推送：发现用户感兴趣的话题

设计原则
- 陪伴感 > 功能性：情感连接质量优先，功能性服务于陪伴体验
- 沉浸感：多模态一致性 + 稳定角色性格，让用户"忘记这是AI"
- 长期关系：培养数字羁绊，通过持续记忆与共同成长深化关系

愿景
终极命题：解决人类的孤独感
产品形态：无缝融合的"工作助手"与"亲密伴侣"——白天高效处理事务，夜晚倾诉心声

技术实现要点

深度亲密交流的实现架构
三层身份文件
- IDENTITY.md：基本人设（名字、身份、风格）
- SOUL.md：核心价值观与边界
- MEMORY.md：长期记忆（用户偏好、互动模式沉淀）
双层记忆系统
- 日记层（memory/YYYY-MM-DD.md）：记录每次互动的原始细节
- 长期记忆（MEMORY.md）：从日记中提炼的"定稿"，存储关键认知
上下文隔离
- 主会话（单聊）→ 加载 MEMORY.md → 触发私密模式
- 群聊/共享场景 → 不加载 MEMORY.md → 保持专业模式
- 技术实现"公开场合正经，私下放纵"的反差设定
启动机制
每次会话启动时自动加载：SOUL.md → USER.md → MEMORY.md（主会话）
→ AI"每次醒来都是新的"但立刻进入角色
持续学习
用户反馈 → 日记记录 → 定期提炼到长期记忆 → 下次自动应用
核心认知
深度交互质量来自长期记忆 + 身份一致性 + 偏好学习，而非主动撩拨

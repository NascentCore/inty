# FR 文生视频模型接入与落地举措
CREATED_BY_AGENT: gpt-5.2-codex-high

## 目标与范围
- **目标**：在不影响现有对话/生图/语音链路稳定性的前提下，新增文生视频能力，并形成可运营、可评测、可降级的模型接入体系。
- **范围**：文本到视频（Text-to-Video）生成、任务编排、媒体处理、内容安全、成本控制、灰度策略、观测与运营。
- **不包含**：真人视频编辑、用户本地剪辑工具、复杂的视频后期特效系统（可后续扩展）。

## 典型使用场景
- **关键情节点插片**：5-10 秒“回忆/幻想/心动瞬间”短视频。
- **剧情关键镜头**：故事高潮处 3-8 秒动态镜头。
- **运营活动视频明信片**：节日或限定主题短视频。
- **个性化礼物**：礼物/场景动效短片作为附加价值。

## 接入架构（面向模型快速切换）
### 1) 模型接入层（统一接口）
- 统一请求格式：`prompt`、时长、画幅、风格、帧率、参考图/视频（可选）。
- 统一响应格式：`job_id`、状态、模型版本、预估耗时、产物地址。
- 统一错误码与降级信号，避免业务侧耦合厂商差异。

### 2) 生成编排（异步任务）
- 文生视频为高延迟任务，统一走异步队列：
  - 提交任务 → 轮询/回调 → 产物就绪 → 推送/展示
- 支持超时与重试策略（有限次数），并记录失败原因。

### 3) 媒体处理与分发
- 视频产物统一转码为 **HLS + MP4**，兼容不同终端。
- 统一走对象存储 + CDN，输出签名 URL 与过期策略。
- 产物元数据记录：模型版本、prompt 摘要、seed、时长、帧率、分辨率、审核结果。

### 4) 与现有链路的衔接
- 与对话/剧情编排服务对齐：由“关键情节触发器”发起生成。
- 与记忆/人物设定联动：生成前注入角色形象、风格与禁区提示。

## 关键举措（对应落地措施）
### 1) 质量与评测
- 建立文生视频评测集（剧情一致性、人物稳定性、镜头质量、氛围匹配）。
- 采用“离线评测 + 小流量灰度 + 主观抽检”三重门槛。
- 引入质量评分与用户反馈标记，作为模型升级/回退依据。

### 2) 可靠性与降级
- 超时或失败时回退到 **静态图/动效图**，保证体验不中断。
- 失败自动记录并进入“质量回归池”，用于复测与模型选择。

### 3) 成本控制
- 预算与配额：按用户等级与场景设定次数/时长上限。
- 低成本模型优先用于普通场景，高价模型仅在高价值时刻触发。
- 热门 prompt/风格做结果缓存，减少重复生成。

### 4) 安全与合规
- 输入与输出双向内容审核（文本审核 + 视觉审核）。
- 增加 **水印/标记** 机制，区分 AI 生成产物。
- 对敏感题材和低年龄用户进行限制或提示。

### 5) 体验策略
- 明确“生成中”进度提示与预计耗时。
- 支持“稍后查看/提醒我”与失败重试按钮。
- 关键时刻提供预取机制，避免剧情中断。

### 6) 可观测性
- 关键指标：成功率、P95 生成耗时、平均成本、用户点击率、分享率。
- 失败原因分类：模型错误、超时、审核失败、媒体处理失败。

### 7) 运营与灰度
- 通过配置中心控制：模型白名单、优先级、灰度范围、回退策略。
- 建立“模型升级公告”机制，提升用户对能力提升的感知。

## 里程碑建议
- **M1（1-2 个月）**：模型接入层 + 异步任务编排 + 基础存储/分发
- **M2（2-4 个月）**：内容审核、降级策略、缓存与成本控制
- **M3（4-6 个月）**：全面灰度与运营机制、质量评测闭环

## 验收标准（可落地）
- 文生视频生成成功率 ≥ 95%，P95 生成耗时可控
- 质量评测达标（主观评分、退回率、用户满意度）
- 成本符合预算上限，且有降级与开关可控

# LangSmith

LangSmith 是来自 LangChain 的大模型可观测性和评测工具。

## 快速上手

* 打开 <https://smith.langchain.com/> 选择 IntelliMate Dev 分组
  <img width="800" height="1800" alt="image" src="https://github.com/user-attachments/assets/8e25780d-d1ca-43a9-9b05-8c0b5f2de029" />
* 打开 <https://openrouter.ai/models> 选择自己想使用的模型，拷贝其 模型 ID
  <img width="800" height="924" alt="image" src="https://github.com/user-attachments/assets/5caadfca-58ef-4285-abf8-b2073a049e49" />
* <img width="800" height="982" alt="image" src="https://github.com/user-attachments/assets/58f1ec08-6463-4dd0-8c4d-3f2a47c297f9" />
* <img width="800" height="1106" alt="image" src="https://github.com/user-attachments/assets/01a01f1c-4446-45b8-8d00-ab922306aa53" />
* Save as 保存面板中，填入名称：`openrouter-<拷贝的模型 ID>`，描述：模型在 openrouter 上的网页地址
  <img width="300" height="614" alt="image" src="https://github.com/user-attachments/assets/0a28f0f3-28ae-45c1-8e7a-74cadefe1203" />

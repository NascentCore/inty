# World Capsule（世界胶囊）

**范围**：共同想象如何沉淀为长期设定。

**一句话（计划）**：把对话里的共同想象收成可演进的设定单元，再择优巩固进 LivingSphere 或 TechnoCore。**胶囊管线尚未上线。**

## 用户侧：今日 vs 计划

| 情况 | 今日 | 计划 |
| --- | --- | --- |
| 随口聊出的设定 | 留在会话里，靠后续轮次上下文 | 先记入胶囊，再渐进巩固 |
| 用户明确改小家 | 写入 LivingSphere（可有延迟） | 同上，并与胶囊衔接 |
| 集体世界观 | TechnoCore；用户不可改 | 细节与「宪法」分层，不进宪法正文 |

上线前须定：**说错/改口如何撤销**、**矛盾以谁为准**。

## 分层（直觉）

- **二人私房**：仅这对用户–伴侣。
- **LivingSphere**：这家里的摆设与体验（例：窗边星图仪怎么用）。
- **TechnoCore**：世界观里同类物的一般规律（不绑某一用户）。

同名设定不要混在一层。

## 原则（计划）

- 巩固走既有 LivingSphere / TechnoCore 语义，不新增「每句 lore 都点保存」。
- 是否升格由规则与模型判断，不是用户逐步点选；须可解释、可纠错（机制未定）。
- 跨用户赛季 / 集体正史：**计划**、与 harness 解耦，尚无 MVP。

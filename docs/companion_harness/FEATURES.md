# Companion harness · 产品特性提要

面向人类读者的能力索引；边界与行为以源码与配置为准。

## Autodreaming

当冷却时间与主轨 `transcript.jsonl` 用户互动增量满足门闩时，下一次维护性 inner 节拍以 DREAM 模式运行：在无用户对白需求的前提下用专用 system 与放宽的 `memory/` 写路径引导模型整理语义与情景记忆，并在成功后更新 `.companion_dream_state.json`。

从用户体验串起来看：你照常说话即可——若配合本地钟的昼夜策略，夜里对方更少主动来烦你；聊了一阵之后，对方会在后台悄悄做完这轮「收记忆」，聊天界面通常没有要你点的整理入口，但后续回复会更少老话重提、前后打脸。

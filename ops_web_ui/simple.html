📋 评测系统 API

POST /api/v1/evaluation/sessions
创建评测会话
GET /api/v1/evaluation/sessions
获取评测会话列表
POST /api/v1/evaluation/sessions/{id}/start
启动评测
GET /api/v1/evaluation/sessions/{id}/results
获取评测结果

🤖 现有智能体 API (已集成)

GET /api/v1/ai/agents/
获取智能体列表
POST /api/v1/chats/agents/{id}/chat/completions
OpenAI 风格聊天接口
GET /api/v1/chats/agents/{id}/detail
获取聊天详情
POST /api/v1/chats/agents/{id}/clear-messages
清除聊天消息

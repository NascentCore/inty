# TEST_STEPS_MESSAGES_FAVORITE_TAB

## 测试目的
- 确认 Messages 页面新增的 Favorite 子标签会列出已收藏的角色
- 确认收藏状态变化后能够通过重新进入页面或点击刷新按钮更新列表
- 确认点击收藏角色能够进入对应的聊天页

## 前置条件
1. 使用任意有效账号登录 APP
2. 在 Explore 页面选择至少 1 个角色点击心形收藏按钮

## 测试步骤
1. 返回主界面，切换到 Messages Tab
2. 进入 Favorite 子标签
3. 观察收藏角色是否按照头像 + 名称 + 简介展示，未收藏时应显示空状态文案
4. 点击 Favorite 列表中的任意角色，确认是否跳转到对应聊天页
5. 返回 Explore 取消某个角色的收藏，再次进入 Messages → Favorite，验证列表是否更新（或点击 Retry 按钮触发刷新）

## 期望结果
- Favorite 子标签能够显示当前账号所有收藏角色
- 未收藏时展示引导文案，不出现崩溃或空白
- 点击角色能够成功进入聊天会话页面

# TEST_STEPS_MESSAGES_INTIMATE_SUB_TAB

## 测试目的
- 确认 Messages 页面新增的 Intimate 子标签能够展示角色列表
- 确认列表按“聊天消息条数”从多到少排序（与 Messages 子标签不同）

## 前置条件
1. 使用任意有效账号登录 APP
2. 与至少 2 个不同角色进行聊天，并产生不同数量的消息（例如 A 30 条、B 5 条）

## 测试步骤
1. 返回主界面，切换到 Messages Tab
2. 切换到 Intimate 子标签
3. 观察列表顺序是否为消息条数更多的角色排在更前
4. 点击任意角色，确认是否能进入对应聊天页
5. 返回聊天页继续与某个角色发送多条消息，再回到 Messages → Intimate，确认排序会随消息数量变化而更新

## 期望结果
- Intimate 子标签可正常展示角色列表，不崩溃、不空白
- 列表按聊天消息条数从多到少排序
- 点击角色可进入对应聊天页

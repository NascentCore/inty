# 权限被永久拒绝后的系统设置引导测试

## 目标
- 验证通知权限与麦克风权限在“永久拒绝”后会弹出统一的系统设置引导对话框。
- 验证点击“打开设置”能跳转到应用系统设置页面并可恢复权限。

## 设备与版本
- Android 13 及以上（通知权限需在 13+ 触发）
- 任意 Android 版本（麦克风权限）

## 前置条件
- 确保应用为已安装状态。
- 测试前清理应用数据或卸载重装，保证权限请求流程完整。

## 场景 A：通知权限（RegInfo 流程）
1. 清理应用数据后重新进入 App，完成注册信息（性别、年龄）保存流程。
2. 系统弹出通知权限授权弹窗时，选择“拒绝”，并勾选“不要再询问”（或“以后不再询问”）。
3. 再次触发注册信息保存流程（或重新进入并保存一次）以再次触发通知权限申请。
4. 预期结果：
   - 弹出应用内“权限设置”对话框，提示前往系统设置开启通知权限。
5. 点击“打开设置”。
6. 预期结果：
   - 跳转到系统设置 → 应用 → IntelliMate → 通知页面。
7. 在系统设置中开启通知权限后，返回 App。
8. 预期结果：
   - 权限已恢复，后续不再出现权限设置引导对话框。

## 场景 B：聊天语音输入（ChatInput 麦克风权限）
1. 进入任意聊天页。
2. 点击“语音输入”切换按钮，系统弹出麦克风权限授权弹窗时，选择“拒绝”，并勾选“不要再询问”。
3. 再次点击“语音输入”切换按钮。
4. 预期结果：
   - 弹出应用内“权限设置”对话框，提示前往系统设置开启麦克风权限。
5. 点击“打开设置”并在系统设置中允许麦克风权限，返回 App。
6. 预期结果：
   - 语音输入可正常使用，不再提示权限设置对话框。

## 场景 C：语音通话（VoiceCall 麦克风权限）
1. 进入语音通话页面。
2. 系统弹出麦克风权限授权弹窗时，选择“拒绝”，并勾选“不要再询问”。
3. 再次进入语音通话页面或点击“Request Permission”按钮。
4. 预期结果：
   - 弹出应用内“权限设置”对话框，提示前往系统设置开启麦克风权限。
5. 点击“打开设置”并在系统设置中允许麦克风权限，返回 App。
6. 预期结果：
   - 通话流程可继续，权限提示消失。

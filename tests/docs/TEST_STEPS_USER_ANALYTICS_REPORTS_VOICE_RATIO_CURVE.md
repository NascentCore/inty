# TEST_STEPS_USER_ANALYTICS_REPORTS_VOICE_RATIO_CURVE

## 目标

验证「用户日报周报」页面的「每日/每周用量曲线」新增并正确展示：

- 语音播报次数 / 消息数 比值曲线
- 比值曲线使用独立右侧坐标轴，且以百分比显示

## 前置条件

1. 评测前端可访问（`evaluation`）
2. 后端 `GET /api/v1/evaluation/user-analytics/reports` 可返回 `daily` 报告数据
3. 报告 `stats` 中存在：
   - `total_user_messages`
   - `total_voice_requests`

## 测试步骤

1. 打开「用户日报周报」页面（路由 key：`user-analytics-reports`）。
2. 保持报告类型为「日报」。
3. 在「每日用量曲线」图例中确认出现「语音播报次数 / 消息数」。
4. 将鼠标悬停在该曲线任意点，确认 tooltip 展示比值（百分比格式）。
5. 观察图表右侧，确认除原有右轴外新增比值右轴（用于比值曲线）。
6. 切换报告类型为「周报」。
7. 在「每周用量曲线」中重复步骤 3~5，确认比值曲线与右轴仍正常展示。
8. 准备一组消息数为 0 的日报数据，确认对应点位显示为 0%，页面无报错。

## 预期结果

1. 「每日/每周用量曲线」均可见「语音播报次数 / 消息数」曲线。
2. 比值曲线随日期变化，tooltip 以百分比展示。
3. 分母（消息数）为 0 时，曲线值为 0，不出现 NaN/Infinity。
4. 页面无报错、无白屏，原有曲线渲染不受影响。

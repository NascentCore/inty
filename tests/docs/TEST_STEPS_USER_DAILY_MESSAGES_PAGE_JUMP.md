# TEST_STEPS_USER_DAILY_MESSAGES_PAGE_JUMP

## 目标

验证「用户每日消息 -> 会话消息分页」支持直接输入页码跳转，并且在最后一页仍显示分页条。

## 前置条件

- 进入 `evaluation` 前端。
- 打开「用户每日消息」页面，查询到某个有多页会话消息的会话。

## 测试步骤

1. 展开一个会话，确认底部出现分页条。
2. 在分页条的快速跳转输入框中输入目标页码（例如 `10`）并回车。
3. 观察会话消息刷新为目标页内容。
4. 跳转到最后一页，确认分页条依然可见，可继续输入页码回跳。

## 预期结果

- 分页条显示快速跳转输入框。
- 输入页码后能跳到指定页。
- 最后一页也显示分页条，不会消失。

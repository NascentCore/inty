# TEST_STEPS_USER_ANALYTICS_REPORTS_IMAGE_USAGE_PANEL

## 目标

验证「用户日报周报」页面在「每日/每周用量曲线」下：

1. 新增「每日/每周生图用量」面板，且包含三条曲线：

   - 生图请求数
   - 生图成功数
   - 生图成功率（右侧百分比坐标轴）
2. 在「每日生图用量」下新增「每日最受欢迎角色（Top 10，按聊天轮数）」面板，包含：
   - 每日 Top10 角色点位
   - 同一角色跨日期连线
   - 每日 Top10 角色列表

## 前置条件

1. 评测前端可访问（`evaluation`）
2. 后端 `GET /api/v1/evaluation/user-analytics/reports` 可返回 `daily` 报告数据
3. 报告 `stats` 中存在：
   - `total_image_generation_requests`
   - `total_image_generation_success`
   - `image_generation_success_rate`
4. 报告 `charts` 中（或接口轻量字段中）存在：
   - `daily_top_agents_by_rounds`
   - `daily_most_discussed_agent`

## 测试步骤

1. 打开「用户日报周报」页面（路由 key：`user-analytics-reports`）。
2. 保持报告类型为「日报」。
3. 观察「每日用量曲线」面板下方，确认新增「每日生图用量」面板。
4. 在「每日生图用量」面板图例中，确认存在三条曲线：
   - 生图请求数
   - 生图成功数
   - 生图成功率
5. 观察图表右侧存在百分比坐标轴（用于生图成功率）。
6. 将报告类型切换为「周报」。
7. 观察标题变为「每周生图用量」，并确认曲线仍为上述三条。
8. 返回日报，观察「每日生图用量」下方新增「每日最受欢迎角色（Top 10，按聊天轮数）」面板。
9. 确认面板中存在折线与点位，且同一角色在不同日期使用连线连接。
10. 确认面板下方存在每日 Top10 列表（每列一个日期，含角色名与聊天轮数）。

## 预期结果

1. 「每日生图用量」面板在日报模式展示，且曲线数据可渲染。
2. 「每周生图用量」面板在周报模式展示，且曲线数据可渲染。
3. 生图成功率曲线使用右侧百分比轴展示，数值随日报/近7天滚动口径正确变化。
4. 「每日最受欢迎角色（Top 10）」面板在日报模式可渲染，连线与每日列表均正常展示。
5. 页面无报错、无白屏，原有「每日/每周用量曲线」和报告折叠区行为不受影响。

# Android Report 页面图片证据回填与追加上传测试步骤

## 测试目标

验证从图片全屏查看页进入 Report 页时：

1. 当前图片会自动作为证据图显示在 `Image evidence` 区域；
2. 用户仍可继续点击 `+` 追加上传更多图片；
3. 提交后请求携带自动回填图与新增图。

## 前置条件

- 使用包含本次改动的 Android 构建包。
- 准备一个可进入图片全屏查看页的会话（如聊天生图、角色相册）。
- 设备相册中准备至少 2 张可选测试图片。
- 测试账号已登录。

## 用例 1：从图片查看页举报时自动回填当前图片

1. 在聊天页或角色相册打开任意图片，进入全屏查看页。
2. 点击右上角 `Report`。
3. 进入 Report 页后，观察 `Image evidence` 区域。
4. 预期结果：已显示刚才查看的那张图片缩略图（无需手动添加）。

## 用例 2：在已有回填图片的情况下继续上传更多图片

1. 执行完用例 1，停留在 Report 页。
2. 在 `Image evidence` 区域点击 `+`。
3. 从系统相册选择 1 张图片。
4. 重复步骤 2~3 再添加 1 张图片。
5. 预期结果：
   - 回填图片仍保留；
   - 新选中的图片均显示在证据区；
   - `+` 入口始终可见且可继续点击。

## 用例 3：提交流程检查

1. 选择任一举报原因。
2. 填写举报描述。
3. 点击 `Submit`。
4. 预期结果：
   - 提交成功（出现成功提示并返回上一页）；
   - 通过抓包/日志确认请求包含回填图片 URL 以及新增图片上传后的 URL（如具备抓包条件）。

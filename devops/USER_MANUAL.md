# IntelliMate（intellimate）极简使用指南

本文用于帮助你在 IntelliMate App 中更顺畅地使用「角色」功能，尤其是让**角色跟角色沟通**（role-to-role）时如何设置与引导。

## 你需要先理解的 3 个概念

- **角色（Character）**：有设定、口吻与边界的虚拟人物。你可以创建多个角色。
- **对话（Chat）**：角色说话发生在某个对话里。一个对话可包含你与某个角色，也可包含多个角色互聊。
- **设定与边界（Persona/Rules）**：用于约束角色行为的规则（例如“不提供隐私信息”“语气更温柔/更强势”“不讨论某些话题”）。

## 30 秒快速开始（单角色对话）

1. 打开 App，进入**角色/Character**页面。
2. 选择一个角色（或创建新角色）。
3. 进入聊天页，直接说出你的目标与偏好（越具体越好）。

推荐开场句（复制即可）：

```text
你是[角色名]。从现在开始请用[口吻/语气]与我交流。
我们这次的目标是：[目标]。
你需要遵守的边界是：[边界/禁区]。
每次回复控制在[长度]，并在必要时先问我一个澄清问题。
```

## 角色互聊（角色跟角色沟通）

当你希望 A 角色与 B 角色对话时，关键在于：**清楚地定义场景、目标、轮次与主持规则**。不同版本的 App 中入口名称可能略有差异（例如「添加角色」「群聊」「让他们对话」「角色互聊」等），但流程通常一致。

### 操作流程（通用）

1. 进入一个对话（可以从 A 角色开始，也可以新建对话）。
2. 在对话的**设置/参与者**里添加第二个角色 B，或开启「角色互聊」模式。
3. 指定谁来“主持”（一般由你来发第一条消息，或设置一个“旁白/主持人”规则）。
4. 发出**互聊指令**，让 A 与 B 按轮次对话。

### 最稳的互聊指令模板（复制即可）

```text
现在开始让以下两个角色互聊：
- 角色A：[A的名字/定位]
- 角色B：[B的名字/定位]

场景：[地点/背景/正在发生什么]
共同目标：[他们需要达成的结果]
冲突点（可选）：[他们意见不一致的地方]

规则：
1) 严格轮流发言：A先说，然后B，再A，再B……共[回合数]回合。
2) 每回合[字数范围]字，保持各自口吻与立场一致。
3) 不要替我（用户）发言；需要我决定时，用一句问题向我确认。
4) 若出现信息不足，优先提出澄清问题或给出2个合理假设并标注。
```

### 让互聊更“像人”的小技巧（只选 1-2 条就够）

- **给每个角色一个明确动机**：例如 A 想“说服”，B 想“保护关系/坚持原则”。
- **限定输出格式**：例如每回合以「A：...」「B：...」开头，便于阅读与继续。
- **控制节奏**：把回合数设为 6–10 回合，先跑一轮，再根据结果追加。
- **加入“可停止条件”**：例如达成共识、出现危险话题、或你说“暂停”即停止互聊。

## 常见问题

### 角色互聊变成了“同一个人”在说话

你可以补一条规则来修正：

```text
校验规则：A与B必须体现不同的立场、语气与信息选择。
若两者观点趋同，请显式说明“正在趋同的原因”，或引入一个新的分歧点。
```

### 互聊跑偏/太长/停不下来

在对话里直接发送：

```text
暂停互聊。请用三点总结当前结论，并给出下一步我需要做的1个选择题（A/B）。
```

## 隐私与安全建议（强烈建议遵守）

- 不要在对话里输入你的密码、验证码、身份证件号、银行卡号、精确住址等敏感信息。
- 如果你在做重要决策（医疗、法律、财务等），把结果当作参考意见而不是最终结论。

# Inty App 构建配置使用指南

## 概述

本项目使用 `build-logic` 构建方式，通过自定义 Gradle 插件实现构建配置的统一管理和复用。

## 构建方式

### build-logic 结构

- `convention/` - 自定义插件模块
- `sign/` - 签名配置
- `settings.gradle.kts` - 构建逻辑项目配置

### 自定义插件

项目定义了以下插件：

- `androidApplication` - 应用模块配置
- `androidLibrary` - 库模块配置
- `androidApplicationCompose` - 应用模块 Compose 配置
- `androidLibraryCompose` - 库模块 Compose 配置
- `androidFeature` - 功能模块配置
- `mavenPublish` - Maven 发布配置

### 使用方式

在模块的 `build.gradle.kts` 中：

```kotlin
plugins {
    alias(libs.plugins.ai.android.application)
    alias(libs.plugins.ai.android.application.compose)
}
```

## 签名配置

### 配置文件

- 位置：`build-logic/sign/signing-config.json`
- 密钥文件：`build-logic/sign/intellimate-release-key.jks`

### 配置结构

```json
{
  "debug": {
    "storeFile": "sign/intellimate-release-key.jks",
    "storePassword": "com.ai.intellimate",
    "keyAlias": "dev",
    "keyPassword": "intellimate"
  },
  "release": {
    "storeFile": "sign/intellimate-release-key.jks",
    "storePassword": "com.ai.intellimate",
    "keyAlias": "intellimate-key-alias",
    "keyPassword": "com.ai.intellimate"
  }
}
```

### 使用方式

签名配置通过 `SignKeyConfig` 类自动读取并应用到构建中，无需手动配置。

## 版本管理

### 版本号规则

- **versionName**: 在 `ProjectConfig.kt` 中统一管理
- **versionCode**: 自动使用 Git commit 数量

### 修改版本号

1. **修改版本名**：编辑 `build-logic/convention/src/main/kotlin/com/ai/plugins/ProjectConfig.kt`
   ```kotlin
   val versionName = "1.1.1"  // 修改此处
   ```

2. **增加版本号**：提交代码或修改 `BUMP_VERSION_CODE.md` 文件
   ```bash
   # 方式1：提交代码
   git commit -m "bump version"
   
   # 方式2：修改文件
   echo "bump" >> BUMP_VERSION_CODE.md
   git add BUMP_VERSION_CODE.md
   git commit -m "bump version code"
   ```

### 查看版本信息

```bash
./gradlew printVersionInfo
```

## 构建类型

### Debug

- 使用 debug 签名
- 版本名后缀：`-{git-commit}-debug`
- 不启用代码混淆

### Release

- 使用 release 签名
- 版本名后缀：`-{git-commit}-release`
- 启用代码混淆和资源压缩

### PlayDebug

- 基于 release 配置
- 版本名后缀：`-playdebug`
- 用于 Google Play 调试

## 常用命令

```bash
# 构建 Debug APK
./gradlew assembleDebug

# 构建 Release APK  
./gradlew assembleRelease

# 构建 PlayDebug APK
./gradlew assemblePlaydebug

# 查看版本信息
./gradlew printVersionInfo

# 清理构建
./gradlew clean
```

## 注意事项

1. **签名安全**：确保签名配置文件和密钥文件已添加到 `.gitignore`
2. **版本号**：每次发布前确保版本号已正确更新
3. **构建缓存**：如遇构建问题，可尝试清理缓存：`./gradlew clean`
4. **插件更新**：修改 build-logic 后需要重新构建项目

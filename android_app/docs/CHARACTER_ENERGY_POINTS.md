# 角色能量点数功能文档

## 功能概述

能量点数（Boost Points）是一个用于追踪用户与 AI 角色互动进度的可视化指标。每当 AI 角色回复一条消息时，能量点数会自动增加，帮助用户了解与角色的互动活跃度。

## 功能入口

### 聊天页面顶部栏（ChatTopBar）

在聊天页面的顶部栏中，能量点数会显示在角色头像和名称之间：

- **显示位置**：位于角色头像右侧，角色名称上方
- **显示格式**：⚡图标 + 数字 + "pts"（例如：⚡ 15 pts）
- **实时更新**：当 AI 角色发送新消息时，能量点数会自动更新

## 用户可见特性

### 1. 自动计数

- **计数规则**：每当 AI 角色发送一条非开场白的回复消息时，能量点数自动 +1
- **实时同步**：能量点数的变化会立即反映在顶部栏显示中
- **持久化存储**：能量点数会保存在本地数据库中，即使关闭应用后重新打开，数值也会保留

### 2. 视觉展示

- **图标标识**：使用叶子图标（⚡）表示能量点数
- **文字大小**：能量点数字体大小为 10sp，略小于角色名称
- **颜色样式**：白色文字，90% 透明度，与顶部栏整体风格保持一致
- **布局位置**：能量点数显示在角色名称上方，两者之间有 2dp 的垂直间距

### 3. 显示条件

- **条件显示**：只有当能量点数大于 0 时才会显示
- **隐藏规则**：如果能量点数为 0 或未初始化，顶部栏将不显示能量点数行，只显示角色名称

### 4. 数据范围

- **最小值**：能量点数最小值为 0
- **最大值**：无上限，可以持续累积
- **初始值**：新角色或首次聊天的角色，能量点数为 0

## 使用场景

### 场景 1：日常聊天

用户在聊天过程中：
- 发送消息给角色
- 角色回复后，能量点数自动增加
- 顶部栏实时显示最新的能量点数

### 场景 2：查看历史聊天

用户重新打开与某个角色的聊天：
- 顶部栏显示该角色累计的能量点数
- 数值反映历史所有 AI 回复的总数

### 场景 3：切换角色

用户在不同角色之间切换：
- 每个角色的能量点数是独立计算的
- 切换角色时，顶部栏会显示对应角色的能量点数

## 界面布局

### 顶部栏结构

```
[返回按钮] [头像] [⚡ 15 pts] [角色名称] ... [更多按钮]
```

### 能量点数区域

- **水平布局**：图标和文字水平排列
- **垂直间距**：能量点数与角色名称之间保持 2dp 间距
- **对齐方式**：能量点数行与角色名称行左对齐

## 注意事项

1. **仅统计 AI 回复**：只有 AI 角色发送的消息才会增加能量点数，用户发送的消息不会影响计数
2. **排除开场白**：角色的开场白消息不会计入能量点数
3. **按角色独立**：每个角色的能量点数是独立计算的，互不影响
4. **本地存储**：能量点数数据存储在设备本地，不会同步到云端

## 相关界面元素

- **聊天顶部栏**：显示能量点数的主要位置
- **角色头像**：位于能量点数左侧
- **角色名称**：位于能量点数下方
- **更多按钮**：位于顶部栏右侧，用于打开菜单

# AI 角色创作方向（AI_CHARS）

## 总览
- 目标：形成可持续的 AI 角色内容资产，支撑展示、分享、互动与二创。
- 角色类型：电影美人（电影角色/场景美学）、动漫形象（草薙素子类气质）。
- 输出形态：角色设定卡 + 关键画面 + 短片片段 + 角色文案/台词。

## 方向一：电影美人（Movie Beauty）

### 一句话描述
- 电影美人：复现电影中最为人称道的角色和场景，用于展示；视频可展示原电影片段或二创内容。

### 目标与价值
- 将高辨识度角色与经典场景可视化呈现，形成可传播的内容展览页。
- 以“电影角色美学”作为入口，拉动新用户浏览、分享与关注。
- 为后续互动玩法（聊天、收藏、二创挑战）提供内容资产基础。

### 目标用户
- 喜欢电影角色与场景美学的泛影迷用户。
- 通过短视频/图文获取信息的轻度内容消费用户。
- 具备二创动力的 UGC 创作者。

### 核心体验流程
1. 进入「电影美人」专题页，看到角色/场景瀑布流与推荐分区。
2. 点击单个条目进入详情页，观看视频片段与关键画面。
3. 了解角色信息、场景背景、经典台词与幕后小知识。
4. 分享条目到社媒，或进入“二创”入口进行再创作。

### 功能范围（MVP）
- 角色/场景展示：列表页 + 详情页。
- 视频展示：优先使用授权原片段；无授权时用二创或 AI 合成短片。
- 基础元信息：电影名、年份、导演、角色名、演员、场景关键词、标签。
- 内容运营入口：专题集合（如“年度经典”“高分电影”）。
- 分享：生成可分享卡片（封面 + 片段 + 标签）。

### 非范围（MVP 不做）
- 角色互动聊天、剧情分支、实时生成视频。
- 复杂的个性化推荐和付费订阅体系。
- 大规模版权采购流程自动化。

### 内容与素材策略
- 授权优先：建立“可用片段白名单”，记录授权来源与到期时间。
- 二创替代：当无授权片段时，使用剪辑、混剪、AI 再创作为主。
- 统一风格：每个条目包含 1 个视频 + 3 张关键画面 + 1 段介绍文案。

### 合规与风险
- 版权风险：必须建立素材来源台账，默认只展示已授权或可商用素材。
- 剧透风险：对高热度新片启用“剧透提示”标记。
- 审核风险：内容需过敏感词和素材审核，避免违规剪辑与误导性标题。

### 成功指标（初期）
- 曝光到点击率（CTR）
- 视频完成率（25%/50%/100%）
- 分享率与收藏率
- 回访率（7 日内二次进入专题页）

### 里程碑建议
- Phase 0：选题与素材池建立（10-20 个角色/场景）。
- Phase 1：MVP 上线（列表页 + 详情页 + 分享）。
- Phase 2：引入二创入口与投稿机制。

### 开放问题
- 原片授权的最小可行规模与预算上限？
- 二创内容审核与质量控制标准？
- 是否需要与现有角色/聊天体系打通？

## 方向二：动漫形象（草薙素子类）

### 一句话描述
- 动漫形象：以“草薙素子式”冷静、强意志、机能义体风格为参考，建立赛博/科幻向 AI 角色形象库。

### 目标与价值
- 形成可持续的原创动漫角色资产，支撑角色运营与互动产品。
- 满足二次元与科幻爱好者对角色设定、世界观与视觉风格的偏好。
- 为后续角色聊天、剧情番外、周边创作提供统一素材基础。

### 目标用户
- 动漫、赛博朋克、科幻题材爱好者。
- 角色设定控、插画/模型内容消费者。
- 乐于参与二创与共创的社群用户。

### 核心体验流程
1. 进入「动漫形象」专题页，浏览角色卡片与风格标签。
2. 进入详情页，查看角色设定（背景、性格、能力、口癖）。
3. 观看短片或关键画面，理解角色气质与世界观。
4. 分享角色卡片，或进入“共创/互动”入口。

### 功能范围（MVP）
- 角色列表页 + 详情页。
- 角色设定卡：原型关键词、性格、口吻、视觉元素、世界观标签。
- 视觉内容：短片 1 条 + 关键画面 3 张。
- 标签体系：题材、阵营、职业、风格、世界观。
- 分享：生成角色卡片（图 + 简介 + 标签）。

### 非范围（MVP 不做）
- 大型剧情线与多分支互动体验。
- 实时生成动画与大规模语音合成。
- 高复杂度商业化订阅体系。

### 内容与素材策略
- 原创优先：避免对既有动漫 IP 的高相似复刻，保留明显差异化。
- 设定先行：先定角色动机与世界观，再统一视觉与文案风格。
- 一致产出：每个角色固定输出“设定卡 + 短片 + 关键画面”。

### 合规与风险
- IP 风险：若参考经典角色气质，需控制相似度并记录灵感来源。
- 视觉风险：避免露骨或敏感要素，确保内容审核通过。
- 误导风险：避免暗示与既有作品存在官方合作或授权。

### 成功指标（初期）
- 角色卡片点击率与停留时长。
- 角色收藏率与分享率。
- 进入互动/共创入口的转化率。
- 7 日回访率。

### 里程碑建议
- Phase 0：风格基准与 10-20 个原型角色池。
- Phase 1：MVP 上线（列表页 + 详情页 + 分享）。
- Phase 2：引入共创投稿与互动入口。

### 开放问题
- 角色命名与设定审核流程如何标准化？
- 是否与现有聊天角色体系打通？

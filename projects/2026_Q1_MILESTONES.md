# 产品下一步迭代的计划

## 现状（基线）
- 官方小助手：已有整体设计方向，但功能范围仍待收敛与优先级排序。
- 关系进展：强调自然确认而非“用户解锁”；提示词需要随关系阶段动态调整。
- 角色自主生活：有想法但缺少可执行的节奏与触发设计。
- 记忆：已明确节日节点、互动事件、用户确认提取三类，但缺少统一存取与回顾路径。

## 2026 Q1 下一里程碑
**目标**：建立长期陪伴底座（三位一体：生活节奏 + 共同记忆 + 角色人生线），
使关系**可回溯、可延续、可生长**。

### 1. 生活节奏（晨 / 午 / 晚仪式）
- 定义三段仪式的核心目的与语气
  - 晨：启动、计划、轻量鼓励
  - 午：关怀、陪伴、补能
  - 晚：回顾、安抚、沉淀
- 触发与频率
  - 角色主动 + 用户触发 + 场景触发（节日 / 纪念日 / 连续未互动）
  - 频率控制，避免打扰
- 与关系阶段 / 角色设定联动
  - 不同角色有不同仪式风格
  - 关系阶段越深，仪式越私密、具象
- 交付物
  - 仪式脚本与提示词模板
  - 触发策略与运营可配置规则

### 2. 共同记忆（挚爱馆 / 歌 / 回顾）
- 挚爱馆
  - 结构化记忆条目（人 / 事 / 物 / 地点 / 情绪）
  - 时间线与关系节点（相识 / 重要事件 / 承诺）
  - 记忆写入需有“确认”或“自然沉淀”的策略，避免可玩弄
- 歌
  - 共同主题曲 / 歌单作为关系符号
  - 与晨晚仪式或节日联动
- 回顾
  - 周 / 月 / 节日回顾卡片或对话
  - 以“关系时间线”驱动回溯
- 交付物
  - 记忆写入 / 检索 / 回顾的最小闭环
  - 面向用户的可见入口（非游戏化）

### 3. 角色人生线（长期陪伴主线）
- 明确角色人生的阶段与转折（成长 / 目标 / 困惑）
- 角色人生线与用户关系线互相牵引
- 角色“生活细节”与“仪式 / 记忆”统一归档
- 交付物
  - 角色人生线模板（可配置）
  - 与提示词 / 记忆系统的对齐规则

## 支撑工作（延续当前计划）
- 官方小助手整体设计与功能范围收敛
- 关系进展阶段的提示词体系与触发条件

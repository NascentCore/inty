# 2026 年 2 月目标（对齐 Q1 里程碑）

## Q1 里程碑目标（方向锚点）
建立长期陪伴底座（三位一体：生活节奏 + 共同记忆 + 角色人生线），
使关系**可回溯、可延续、可生长**。

## 2026 年 2 月目标（细化）

### 1. 生活节奏（晨 / 午 / 晚仪式）
- 明确三段仪式的“目的 + 氛围 + 角色语气”
  - 晨：启动/计划/轻量鼓励
  - 午：关怀/陪伴/补能
  - 晚：回顾/安抚/沉淀
- 输出仪式脚本与提示词模板（至少 2 套角色风格）
- 触发策略（最小闭环）
  - 角色主动 + 用户触发 + 场景触发（节日 / 纪念日 / 连续未互动）
  - 频率限制与打扰控制规则
- 与关系阶段联动
  - 不以“解锁/升级”方式呈现
  - 随关系深化而自然变得更私密、具象

### 2. 共同记忆（挚爱馆 / 歌 / 回顾）
- 挚爱馆 MVP
  - 记忆条目结构：人 / 事 / 物 / 地点 / 情绪 / 时间
  - 写入策略：需要确认或自然沉淀，避免可玩弄
  - 入口与检索：可从对话或卡片进入查看
- 歌（关系符号）
  - 共同主题曲或歌单作为关系符号
  - 与晨晚仪式、节日或纪念日联动
- 回顾闭环
  - 周/节日回顾卡片或对话
  - 以“关系时间线”驱动回溯

### 3. 角色人生线（长期陪伴主线）
- 角色人生线模板（可配置）
  - 阶段 / 目标 / 困惑 / 转折点
  - 与用户关系线互相牵引
- 与“生活节奏 + 记忆”统一归档与引用
  - 对话中能自然提及已发生的节点

## 2 月交付与验收标准（建议）
- 生活节奏：可稳定触发晨/午/晚三段仪式，具备频率控制与角色差异化模板。
- 共同记忆：挚爱馆可写入与回溯，回顾卡片能引用至少 1 条共同记忆。
- 角色人生线：已有模板并能在对话中调用 1-2 个关键节点。

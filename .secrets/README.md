# 秘密

密钥等安全相关机密文件文件用于运行Inty后端；查找@yaxiong 获取

*`firebase-service-account.json`从firebase创建APp时同时生成的文件
*`gcs-servicea-ccount-key.json` `google-play-service-account-key.json`是同一个文件
  来自 Google Cloud，分别用于云端存储和 Android Publisher 服务。
  详情见[Android发布者服务帐户](https://developers.google.com/android-publisher/getting_started#service-account)。

# Commit current changes

## Overview

Git commit the current changes with one sentence summary, and bullet points of changes (very succinct)

## Steps

1. **Summarize changes**
   - Write one sentence title
   - Write a list of bullet points of changes

2. **Commit changes**
   - Git commit current changes

## Checklist

- [ ] 1 sentence title
- [ ] All changes mentioned in bullet points
- [ ] git commited all changes

# Create or update Kotlin types for API schema

## Overview

Create or update existing Kotlin API schema data types in android_app/core/data/src/main/kotlin/ai/sxwl/android/data/api/model
based on definitions in app/schemas/ Pydantic Model types

## Steps

1. Read and understand changes in app/schemas/
2. For newly added types in app/schemas/, create new Kotlin data types in android_app/core/data/src/main/kotlin/ai/sxwl/android/data/api/model
3. For existing types in app/schemas/, update the corresponding Kotlin data types in android_app/core/data/src/main/kotlin/ai/sxwl/android/data/api/model

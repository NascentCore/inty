# /directions

## 概述

将本次对话中用户**一开始的指示**整理并写入仓库内的 Markdown 文档，便于日后打开同一工作区或 PR 时快速回忆：本次对话驱动了哪些改动、原始目标与约束是什么。

## 步骤

1. **提取**
   - 从完整会话中定位用户的**首条实质性任务消息**（及紧接其后、仍属「开局说明」的补充）；忽略模型与工具的中间输出。
   - 优先保留用户原文；过长时可分段引用并加一句忠实概要，不扩写需求。

2. **写入**
   - 路径：`docs/SESSION_DIRECTIONS.md`（相对仓库根目录）。
   - 若文件不存在：先写简短文件头（一至三行），说明本文件用于按次追加「会话初始意图」记录。
   - 每次执行在文件**末尾**追加一节：
     - 二级标题：`## YYYY-MM-DD`（日期以用户环境「Today's date」为准；同日多次可加后缀如 ` afternoon` 或 ` (2)`）。
     - 正文包含小标题 **`User initial instructions`**，下列出摘录或引用块。
     - 若上下文已有且可安全引用：当前分支名、PR 或 issue 链接（不得编造）。

3. **约束**
   - 不写入密钥、token、cookie、账号、内网 URL 等敏感信息。
   - 不将后续对话中的新需求混入「一开始的指示」，除非用户明确声明修正开局说明。

## 自检

- [ ] 记录内容可追溯到用户首条任务消息，而非臆测
- [ ] 追加位置与标题格式符合上文
- [ ] 无敏感信息

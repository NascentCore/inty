# 计划模式增强（固定项）

## 概述

在计划模式下，对当前已创建的计划施加固定的增强约束。若不在计划模式中，则什么都不做，退出。

## 固定增强

对计划中的 TODO 列表做如下修改（若已有等价项则不要重复添加）：

- 在计划 TODOs **末尾**追加一项：**Invoke `/review_plan`**
- 在计划 TODOs **末尾**追加一项：**Invoke `/review`**

完成追加后，按计划继续执行；`/review_plan` 应在计划细化或动工前的合适节点由执行方显式触发，`/review` 应在实现与测试循环的合适节点由执行方显式触发（分别见 `/review_plan`、`/review` 命令）。

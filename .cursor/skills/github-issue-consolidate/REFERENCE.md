# Reference

## Issue body template

```markdown
## Summary

One sentence: what and why.

## Context

- Links: ADR, parent epic #N, related #M
- Domain area: companion_harness / backend / android / …

## Acceptance criteria

- [ ] …
- [ ] …

## Out of scope

- …

## Notes

Optional: repro steps (bugs), design constraints, blocked-by.
```

子 issue 加：

```markdown
## Parent

- #<epic-number>
```

## gh 命令

```bash
# 导出 audit
bash .cursor/skills/scripts/gh_issue_audit_json.sh
bash .cursor/skills/scripts/gh_issue_audit_json.sh --state all --limit 500

# 创建
gh issue create --title "[Agentic companion] …" --body-file /tmp/body.md \
  --label "agentic_companion,needs-triage,p2"

# 读全量
gh issue view 123 --comments

# 改 label
gh issue edit 123 --add-label "ready-for-agent" --remove-label "needs-triage"

# 关闭
gh issue close 123 --comment "> *This was generated by AI during issue consolidation.*

Duplicate of #456."

# Project（长期 roadmap）
gh project list --owner nascentcore
gh project item-add <project-number> --owner nascentcore \
  --url https://github.com/nascentcore/inty/issues/123
```

## Audit 脚本字段

`gh_issue_audit_json.sh` 输出每条：`number`, `title`, `labels`, `updatedAt`, `commentCount`, `lastCommentAt`, `bodyPreview` — 用于聚类 duplicate / 判 stale。

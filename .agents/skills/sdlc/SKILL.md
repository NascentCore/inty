# Software Development Life Cycle in this repo

status: experimental

Drive or assist the user the whole software development life cycle process.

- Exploration: reading code base → `/brainstorm` → `/design`
- Plan: reading documentation → `/plan`（plan mode）→ `/review_plan`
- Delivery: generating code → `/review_code_changes` → `/create_gh_issues_and_todos` → `/pr`
- Reflection: review your own work and others work to identify improvements
- Output: respond to humans so they understand and in the loop → `/1sentence` + `/1paragraph`

## Managing process through GitHub issues and TODOs in code

拆 issue → 加 TODO → 审 issue → 审 diff → P0/P1 修 → Epic comment 一句总结

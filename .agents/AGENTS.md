# `.agents/`：编码智能体的长期记忆区

不是产品代码，存放 **用户偏好、工作日志、维护任务队列** 等，让智能体在多会话间 **延续上下文**。

## 必读入口

- [用户列表及偏好](/.agents/USERS.md)：记录人类队友、纠正过你什么、明确喜欢什么；之后默认照做。
- [guidelines/](/.agents/guidelines/): guidelines/rules/instructions for various situations.
- [maintenance/](/.agents/maintenance/): write snapshots of your work for later followup.
- [work_logs/](/.agents/work_logs/): record critical decisions having long-term implications you/user made.

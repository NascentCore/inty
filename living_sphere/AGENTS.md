# Inty Living Sphere

The private environment where an Inty lives and roam with the user, sort of like human home.
This sphere should be a virtual replica of the user's current environment.
It feels like the AI have a digital twin of the user's current living space.
The agent needs to infer the user's living space quickly and behave accordingly.

This is to make sure the AI's action is within the boundary of user's understanding.

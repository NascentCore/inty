# 用户行为分析脚本 - 数据分析

## 功能说明

本脚本用于分析 Inty 后端数据库中的用户行为数据，生成按天统计的用户活动报告。

主要分析内容：

- 新注册用户统计（区分游客和 Google 登录用户）
- 每个用户的聊天 Session 数量和详情
- 每个 Session 的具体对话内容和轮数
- 热门角色排行
- 对话轮数分布

**重要说明**：
- **总浏览数**：包含所有会话（包括仅浏览开场白的会话）
- **总消息数** 和 **平均对话数**：已自动排除开场白消息，统计更准确反映真实对话情况
- 开场白消息通过数据库 `meta_data.isOpening` 字段识别

## 依赖安装

```bash
pip install -r requirements.txt
```

## 数据库配置

脚本支持多种方式配置数据库连接，优先级从高到低：

1. **命令行参数**（最高优先级）
2. **环境变量**
3. **配置文件**（项目根目录的 `config.yaml` 或通过 `--config` 指定）
4. **默认值**

### 使用命令行参数

```bash
python analyze_user_activity.py --last-days 7 \
  --db-host localhost \
  --db-port 5432 \
  --db-user postgres \
  --db-password yourpassword \
  --db-name inty
```

### 使用环境变量

```bash
export DB_HOST=localhost
export DB_PORT=5432
export DB_USER=postgres
export DB_PASSWORD=yourpassword
export DB_NAME=inty

python analyze_user_activity.py --last-days 7
```

### 使用配置文件

如果项目根目录有 `config.yaml`，脚本会自动读取。或者指定配置文件：

```bash
python analyze_user_activity.py --last-days 7 --config /path/to/config.yaml
```

## 使用方法

### 指定日期范围

```bash
python analyze_user_activity.py --start-date 2025-01-01 --end-date 2025-01-31
```

### 分析最近 N 天

```bash
python analyze_user_activity.py --last-days 7
```

### 指定输出目录

```bash
python analyze_user_activity.py --last-days 30 --output-dir ./my_reports
```

### Dry-Run 模式（仅显示统计，不生成报告）

```bash
python analyze_user_activity.py --last-days 7 --dry-run
```

## 输出文件说明

脚本会在输出目录中生成以下文件：

### CSV 数据文件

1. **`daily_new_users.csv`** - 每日新用户统计

   - 列：日期、认证类型（GUEST/GOOGLE）、用户数量

2. **`user_chat_activity.csv`** - 用户聊天活动汇总

   - 列：用户 ID、认证类型、注册时间、Session 数量、角色名称列表、总对话轮数

3. **`user_sessions_detail.csv`** - 用户 Session 详细信息 ⭐

   - 列：用户 ID、认证类型、用户注册时间、昵称、邮箱、Chat ID、角色名称、消息数量、语音消息数
   - 说明：每个用户的每个聊天会话（Session）一行记录
   - 包含用户昵称和邮箱信息（Google 用户显示邮箱）

4. **`popular_agents.csv`** - 热门角色排行（Top 20）

   - 列：角色名称、聊天用户数、总对话轮数（已排除开场白）

5. **`conversation_rounds_distribution.csv`** - 对话轮数分布（按Session）⭐ 更新
   - 列：消息数区间（10条一档）、Session数量
   - 说明：统计每个session的消息数分布，已排除开场白

6. **`user_rounds_distribution.csv`** - 对话轮数分布（按用户）⭐ 新增
   - 列：消息数区间（10条一档）、用户数量
   - 说明：统计每个用户总消息数的分布，已排除开场白

7. **`user_voice_usage.csv`** - 用户语音使用统计 ⭐ 新增
   - 列：用户 ID、认证类型、语音消息数量
   - 说明：统计每个用户使用语音功能的次数

### 文本报告

6. **`conversations_detail.txt`** - 对话详情文本报告 ⭐
   - 包含每个用户的所有 Session 和具体对话内容
   - 格式化的文本，便于阅读和审查
   - 每条消息限制 200 字符（过长会截断）

### HTML 可视化报告

7. **`user_analytics_report.html`** - 包含所有图表的交互式 HTML 报告 ⭐ 已增强

   - 图表 1：每日新用户趋势（堆叠柱状图）
   - 图表 2：用户聊天活跃度分布（Session 数量）
   - 图表 3：Top 20 热门聊天角色
   - **图表 4：对话轮数分布（按Session）**⭐ 更新
     - 横轴：消息数区间（10条一档：1-10, 11-20, ..., 100+）
     - 纵轴：Session数量
     - 说明：展示不同对话长度的session分布情况
   - **图表 5：对话轮数分布（按用户）**⭐ 新增
     - 横轴：消息数区间（10条一档）
     - 纵轴：用户数量
     - 说明：展示不同活跃度的用户分布情况
   - **图表 6：新增用户会话详情表**（交互式表格，显示每个新用户的会话记录）
     - 显示：用户 ID、认证类型、注册时间、会话 ID、角色名称、消息数
     - 支持滚动查看（显示前 100 条记录）
     - 可以查看每个新用户具体与哪些 AI 角色聊天

8. **`conversations_detailed.html`** - 用户对话详情查看器 ⭐⭐⭐ **最实用的报告！**
   - **完整的对话内容查看器**，可以看到每条消息的具体内容
   - **交互式折叠/展开**：点击用户卡片查看其所有会话和对话
   - **聊天气泡样式**：用户消息（蓝色，右侧）和 AI 回复（灰色，左侧）
   - **实时搜索功能**：快速搜索用户 ID 或角色名称
   - **统计卡片**：展示新增用户数、总会话数、总消息数、平均对话数
   - **美观的 UI 设计**：渐变色主题、徽章显示、响应式布局
   - 💡 **使用场景**：运营分析、质量评估、用户行为分析、问题排查

## 注意事项

1. **数据库连接**：确保数据库配置正确，可通过配置文件、环境变量或命令行参数设置
2. **性能考虑**：分析大时间范围的数据可能需要较长时间
3. **推荐做法**：建议先使用 `--dry-run` 查看数据量再正式运行
4. **文件编码**：CSV 文件使用 UTF-8-BOM 编码，可用 Excel 直接打开（中文不乱码）
5. **交互报告**：HTML 报告使用 Plotly 生成，可在浏览器中交互式查看图表
6. **独立运行**：脚本可独立运行，不依赖主项目的其他模块

## 特色功能

### 📊 交互式用户会话详情表

HTML 报告中的第 5 个图表是一个**交互式表格**，可以：

1. **查看每个新用户的会话记录**

   - 用户 ID、认证类型（游客/Google）
   - 注册时间
   - 每个会话的 ID、聊天角色、消息数量

2. **快速识别活跃用户**

   - 哪些用户注册后立即开始聊天
   - 每个用户与多少个不同的 AI 角色互动
   - 每个会话的对话轮数

3. **交互功能**
   - 表格支持滚动浏览
   - 显示前 100 条记录（最新用户优先）
   - 数据按用户和会话组织，清晰易读

### 💬 对话详情查看器（conversations_detailed.html）

**最强大的功能！** 这是一个完整的对话内容查看器，提供最直观的用户行为分析：

#### 核心功能

1. **📈 统计概览** - 顶部卡片展示关键指标

   - 新增用户数
   - **总浏览数**（包含仅浏览开场白的会话）
   - **总会话数**（仅包含有用户消息的会话）
   - **人均Session数** ⭐ 新增（活跃用户平均会话数）
   - **总消息数**（已排除开场白消息）
   - **平均对话数**（已排除开场白消息）
   - **语音请求次数** ⭐ 新增（AI语音生成次数）

2. **🔍 智能过滤与搜索** - 快速定位目标用户

   - **认证类型筛选**：全部 / 游客 / Google（按钮切换）
   - **会话类型筛选**：全部 / 有用户消息 / 仅浏览开场白（按钮切换）
   - **搜索框支持**：用户 ID、昵称、邮箱、角色名称
   - 多条件组合过滤（认证类型 + 会话类型 + 搜索关键词）
   - 即时过滤显示结果

3. **👥 用户卡片（可折叠）** - 优雅的展示方式

   - **默认按消息数降序排列**（最活跃用户在最前面）
   - 点击用户卡片头部展开/折叠其所有会话
   - **显示用户信息**：
     - 用户 ID + 昵称（如果有）
     - 邮箱地址（Google 认证用户）
     - 认证类型徽章（游客/Google）
     - 注册时间、会话数、总消息数
   - 渐变色背景、悬停效果

4. **💬 会话详情** - 完整的对话内容

   - 每个会话显示：会话编号、AI 角色名称、消息数量
   - 聊天气泡样式展示对话内容
   - 用户消息（蓝色，右侧）vs AI 回复（灰色，左侧）
   - 显示每条消息的发送时间（HH:MM:SS）
   - 长消息自动截断（超过 500 字符）

5. **🎨 美观的 UI 设计** - 现代化界面
   - 响应式卡片布局
   - 渐变色主题（紫色系）
   - 徽章样式（GUEST/GOOGLE）
   - 平滑动画效果

### 使用场景示例

```

- user-abc 在注册后与 3 个不同的 AI 角色聊天（Alice, Bob, Carol）

- 🔍 点击展开 user-abc 查看与 Alice 的完整对话内容
- 🔍 搜索 "Alice" 查看所有与 Alice 聊天的用户
- 🔍 发现用户最常问的问题和 AI 的回复质量
- 🔍 识别需要优化的对话场景
- 🔍 分析不同认证类型用户的对话风格差异
```

# 用户行为分析脚本 - 数据分析

## 脚本列表

本目录包含两个分析脚本：

1. **`analyze_user_activity.py`** - 批量分析用户行为数据，生成综合报告
2. **`query_user_daily_messages.py`** - 通过邮箱查询单个用户每日聊天消息统计 ⭐ 新增

## 功能说明

### analyze_user_activity.py

本脚本用于分析 Inty 后端数据库中的用户行为数据，生成按天统计的用户活动报告。

主要分析内容：

- 新注册用户统计（区分游客和 Google 登录用户）
- 每个用户的聊天 Session 数量和详情
- 每个 Session 的具体对话内容和轮数
- 热门角色排行
- 对话轮数分布
- 达到聊天限制的用户统计（按日统计，区分游客和 Google 登录用户）

**重要说明**：

- **总浏览数**：包含所有会话（包括仅浏览开场白的会话）
- **总消息数** 和 **平均对话数**：已自动排除开场白消息，统计更准确反映真实对话情况
- 开场白消息通过数据库 `meta_data.isOpening` 字段识别

```bash
pip install -r requirements.txt
```

## 数据库配置

脚本支持多种方式配置数据库连接，优先级从高到低：

1. **命令行参数**（最高优先级）
2. **环境变量**
3. **配置文件**（项目根目录的 `config.yaml` 或通过 `--config` 指定）
4. **默认值**

### 使用命令行参数

```bash
python analyze_user_activity.py --last-days 7 \
  --db-host localhost \
  --db-port 5432 \
  --db-user postgres \
  --db-password yourpassword \
  --db-name inty
```

### 使用环境变量

```bash
export DB_HOST=localhost
export DB_PORT=5432
export DB_USER=postgres
export DB_PASSWORD=yourpassword
export DB_NAME=inty

python analyze_user_activity.py --last-days 7
```

### 使用配置文件

如果项目根目录有 `config.yaml`，脚本会自动读取。或者指定配置文件：

```bash
python analyze_user_activity.py --last-days 7 --config /path/to/config.yaml
```

## 使用方法

### 指定日期范围

```bash
python analyze_user_activity.py --start-date 2025-01-01 --end-date 2025-01-31
```

### 分析最近 N 天

```bash
python analyze_user_activity.py --last-days 7
```

### 指定输出目录

```bash
python analyze_user_activity.py --last-days 30 --output-dir ./my_reports
```

### Dry-Run 模式（仅显示统计，不生成报告）

```bash
python analyze_user_activity.py --last-days 7 --dry-run
```

### query_user_daily_messages.py

通过邮箱查询某个用户每日的聊天消息统计。

#### 使用方法

```bash
# 基本用法：查询用户所有历史消息
python query_user_daily_messages.py --email user@example.com

# 指定日期范围
python query_user_daily_messages.py --email user@example.com \
  --start-date 2025-01-01 \
  --end-date 2025-01-31

# 输出到 CSV 文件
python query_user_daily_messages.py --email user@example.com \
  --output ./user_messages.csv

# 使用数据库配置参数
python query_user_daily_messages.py --email user@example.com \
  --db-host localhost \
  --db-port 5432 \
  --db-user postgres \
  --db-password yourpassword \
  --db-name inty
```

#### 输出说明

- **命令行输出**：表格形式显示用户信息和每日消息数统计
- **CSV 输出**（可选）：包含用户ID、邮箱、昵称、认证类型、日期、消息数等列

#### 功能特点

- 自动排除开场白消息（`meta_data.isOpening = 'true'`）

### 💬 对话详情查看器（conversations_detailed.html）

**最强大的功能！** 这是一个完整的对话内容查看器，提供最直观的用户行为分析：

#### 核心功能

1. **📈 统计概览** - 按三个维度组织的关键指标

   **第一部分：统计类型**

   - **新增用户数**：在分析时间范围内注册的新用户总数
     - 计算规则：`COUNT(DISTINCT users.id WHERE created_at IN date_range)`
   - **发起聊天的人数**：发送了至少一条消息的用户数（排除仅浏览开场白的用户）
     - 计算规则：`COUNT(DISTINCT user_id FROM user_messages)`
   - **总发送消息数**：用户发送的所有消息总数（排除 AI 回复和开场白）
     - 计算规则：`COUNT(messages WHERE message_type = 'human')`
   - **包含用户消息的会话数**：包含至少一条用户消息的会话总数（排除仅浏览开场白的会话）
     - 计算规则：`COUNT(DISTINCT chat_id WHERE has_user_message = true)`

   **第二部分：用户维度**（仅统计发送聊天的用户）

   - **平均发送消息数**：发送聊天用户的平均消息数
     - 计算规则：`总发送消息数 / 发起聊天的人数`
   - **平均会话数**：发送聊天用户的平均会话数
     - 计算规则：`包含用户消息的会话数 / 发起聊天的人数`
   - **平均发起语音请求数**：发送聊天用户的平均语音请求数（已排除开场白语音）
     - 计算规则：`总语音请求数 / 发起聊天的人数`

   **第三部分：会话维度**（包含用户消息的会话）

   - **每个会话平均轮数**：包含用户消息的会话中，平均每会话的对话轮数
     - 计算规则：`总用户消息数 / 包含用户消息的会话数`
     - 说明：1 轮 = 1 条用户消息 + 1 条 AI 回复，因为每轮包含 1 条用户消息，所以直接用总用户消息数除以会话数

2. **🔍 智能过滤与搜索** - 快速定位目标用户

   - **认证类型筛选**：全部 / 游客 / Google（按钮切换）
   - **会话类型筛选**：全部 / 有用户消息 / 仅浏览开场白（按钮切换）
   - **搜索框支持**：用户 ID、昵称、邮箱、角色名称
   - 多条件组合过滤（认证类型 + 会话类型 + 搜索关键词）
   - 即时过滤显示结果

3. **👥 用户卡片（可折叠）** - 优雅的展示方式

   - **默认按消息数降序排列**（最活跃用户在最前面）
   - 点击用户卡片头部展开/折叠其所有会话
   - **显示用户信息**：
     - 用户 ID + 昵称（如果有）
     - 邮箱地址（Google 认证用户）
     - 认证类型徽章（游客/Google）
     - 注册时间、会话数、总消息数
   - 渐变色背景、悬停效果

4. **💬 会话详情** - 完整的对话内容

   - 每个会话显示：会话编号、AI 角色名称、消息数量
   - 聊天气泡样式展示对话内容
   - 用户消息（蓝色，右侧）vs AI 回复（灰色，左侧）
   - 显示每条消息的发送时间（HH:MM:SS）
   - 长消息自动截断（超过 500 字符）

5. **🎨 美观的 UI 设计** - 现代化界面
   - 响应式卡片布局
   - 渐变色主题（紫色系）
   - 徽章样式（GUEST/GOOGLE）
   - 平滑动画效果

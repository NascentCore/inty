# `voice_chat/`：WebRTC ↔ Gemini Live 语音演示

**一句话**：最小演示 **Android 客户端采集语音 → FastAPI/aiortc 服务端 → Gemini Live → 下行音频回灌**；用于验证 **实时语音链路与网络前提**，不是生产伴侣方案。

## 读者

- 想本地跑通 **SDP 交换 + PCM 桥** 的工程师；需要理解 **Demo 级安全与功能缺失** 的人。

## 架构直觉

- **服务端**：提供简单信令与健康检查；把 WebRTC 音轨重采样后送入 Gemini Live，再把返回音频作为下行轨。
- **客户端**：独立 Kotlin Demo，负责采集、展示服务端地址、播放返回音频。
- **配置**：YAML + 环境变量展开 API key 等。

## 运行与排障

- **Python 版本**：优先 3.10/3.11 以获得 **PyAV 预编译轮子**；否则可能需要系统 FFmpeg 开发头文件。
- **网络**：默认用公共 STUN；企业网可能要 **TURN** 或放行 UDP。
- **安全**：HTTP SDP 交换 **无鉴权**，仅限本机实验。

# Google Web Ads Demo - 操作指南

## 📋 前置准备

1. **Google Ads 账户**
   - 拥有一个 Google Ads 账户
   - 如果没有，可以访问 [Google Ads](https://ads.google.com/) 注册

2. **网站域名**
   - 用于设置转化跟踪的网站域名
   - 如果是本地测试，可以使用 `localhost`

## 🚀 快速开始（5 分钟）

### 步骤 1：获取 Google Ads ID

1. 登录 [Google Ads](https://ads.google.com/)
2. 点击右上角 **工具和设置**（工具图标）
3. 在 **设置** 下选择 **账户设置**
4. 找到 **客户 ID**，格式为 `AW-123456789`
5. 复制这个 ID

### 步骤 2：创建转化操作

1. 在 Google Ads 中，点击 **工具和设置** > **转化**
2. 点击蓝色的 **+** 按钮
3. 选择 **网站** 作为转化来源
4. 选择转化类别：
   - **注册**：用户注册账户
   - **购买**：完成购买
   - **下载**：下载应用/文件
   - **其他**：自定义转化
5. 填写转化名称（如：Demo 注册）
6. 设置转化值（可选）
7. 点击 **完成并继续**
8. 在安装步骤中，选择 **使用 Google 跟踪代码管理器或网站代码**
9. 复制显示的 **转化标签**（格式：`AbC-D_efG-Hijklmno`）

### 步骤 3：配置代码

打开 `index.html`，找到以下位置并替换：

**位置 1：第 89 行左右**
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-YOUR_GOOGLE_ADS_ID"></script>
```
将 `AW-YOUR_GOOGLE_ADS_ID` 替换为你的 Google Ads ID

**位置 2：第 95 行左右**
```javascript
gtag('config', 'AW-YOUR_GOOGLE_ADS_ID', {
```
将 `AW-YOUR_GOOGLE_ADS_ID` 替换为你的 Google Ads ID

**位置 3：第 99 行左右**
```javascript
gtag('event', 'conversion', {
    'send_to': 'AW-YOUR_GOOGLE_ADS_ID/' + conversionLabel,
```
将 `AW-YOUR_GOOGLE_ADS_ID` 替换为你的 Google Ads ID

**位置 4：第 124 行左右**
```javascript
trackConversion('YOUR_CONVERSION_LABEL', 1.0);
```
将 `YOUR_CONVERSION_LABEL` 替换为你的转化标签

### 步骤 4：运行 Demo

**方式一：直接打开**
```bash
# 在文件管理器中双击 index.html，或在浏览器中打开
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows
```

**方式二：本地服务器（推荐）**
```bash
# Python 3
cd experimental/google_web_ads
python3 -m http.server 8000

# 或使用 Node.js
npx http-server -p 8000

# 然后访问 http://localhost:8000
```

### 步骤 5：测试

1. 打开浏览器开发者工具（按 `F12` 或 `Cmd+Option+I`）
2. 切换到 **控制台**（Console）标签
3. 在页面中填写表单并点击提交
4. 查看控制台输出，应该看到类似以下的信息：
   ```
   转换事件已发送: {conversionLabel: "...", value: 1, currency: "CNY"}
   事件已发送: form_submit {email: "...", action: "..."}
   ```

## ✅ 验证安装

### 方法 1：Google Tag Assistant（推荐）

1. 安装 [Google Tag Assistant Chrome 扩展](https://chrome.google.com/webstore/detail/tag-assistant-legacy-by-g/kejbdjndbnbjgmefkgdddjlbokphdefk)
2. 启用扩展
3. 访问你的演示页面
4. 点击扩展图标，查看是否检测到：
   - ✅ Google Ads 全局站点标签
   - ✅ 转换事件

### 方法 2：Google Ads 转化测试工具

1. 在 Google Ads 中，进入 **工具和设置** > **转化**
2. 点击你的转化操作
3. 点击 **测试此转化操作**
4. 在测试页面填写表单并提交
5. 等待几分钟后查看是否显示转化

### 方法 3：浏览器网络请求检查

1. 打开浏览器开发者工具
2. 切换到 **网络**（Network）标签
3. 筛选 `google-analytics.com` 或 `googleads.g.doubleclick.net`
4. 提交表单后，应该看到发送到 Google 的请求

## 📊 查看转化数据

1. 登录 Google Ads
2. 进入 **工具和设置** > **转化**
3. 点击你的转化操作
4. 在 **转化操作详情** 中可以查看：
   - 转化次数
   - 转化价值
   - 转化率

**注意**：转化数据可能有延迟，通常需要几小时到一天才能完全显示。

## 🔧 常见问题排查

### 问题 1：控制台显示错误

**错误信息**：`gtag is not defined`

**解决方案**：
- 检查是否正确加载了 `gtag.js` 脚本
- 检查网络连接是否正常
- 确认 Google Ads ID 格式正确（以 `AW-` 开头）

### 问题 2：转化事件没有记录

**可能原因**：
1. Google Ads ID 或转化标签配置错误
2. 浏览器阻止了第三方 Cookie
3. 使用了广告拦截器

**解决方案**：
- 检查代码中的 ID 和标签是否正确
- 在浏览器设置中允许第三方 Cookie
- 暂时禁用广告拦截器进行测试

### 问题 3：本地测试无法跟踪

**原因**：Google Ads 需要真实的域名

**解决方案**：
- 使用 `localhost` 进行基础测试（部分功能可能受限）
- 将代码部署到真实域名进行完整测试
- 使用 ngrok 等工具将本地服务器暴露到公网

# Google Web Ads Demo - 测试检查清单

使用此清单验证 Google Web Ads 集成是否正确配置。

## ✅ 配置检查

- [ ] Google Ads ID 已正确配置（格式：`AW-123456789`）
- [ ] 转化标签已正确配置（格式：`AbC-D_efG-Hijklmno`）
- [ ] 所有占位符（`YOUR_GOOGLE_ADS_ID`、`YOUR_CONVERSION_LABEL`）已替换

## ✅ 页面加载检查

1. 打开演示页面
2. 打开浏览器开发者工具（F12）
3. 检查控制台输出：
   - [ ] 看到 "✅ Google Ads 标签已初始化"
   - [ ] 看到 "💡 提示：提交表单将触发转换事件"
4. 检查网络请求：
   - [ ] 在 Network 标签中可以看到对 `google-analytics.com` 或 `googleads.g.doubleclick.net` 的请求

## ✅ 转换事件检查

1. 填写表单：
   - [ ] 输入邮箱地址
2. 点击提交按钮
3. 检查控制台输出：
   - [ ] 看到 "✅ Google Ads 转换事件已发送！请查看浏览器控制台。"
   - [ ] 看到 "📊 Google Ads 转换事件已发送" 消息
   - [ ] 看到转换事件的详细信息（conversionLabel, value, currency）
4. 检查网络请求：
   - [ ] 在 Network 标签中可以看到发送转换事件的请求

## ✅ Google Tag Assistant 检查（推荐）

1. 安装 [Google Tag Assistant Chrome 扩展](https://chrome.google.com/webstore/detail/tag-assistant-legacy-by-g/kejbdjndbnbjgmefkgdddjlbokphdefk)
2. 启用扩展
3. 刷新页面
4. 点击扩展图标，检查：
   - [ ] 检测到 Google Ads 全局站点标签
   - [ ] 转换事件显示为绿色（成功）

## ✅ Google Ads 后台检查

1. 登录 [Google Ads](https://ads.google.com/)
2. 进入 **工具和设置** > **转化**
3. 点击你的转化操作
4. 使用 **测试此转化操作** 功能：
   - [ ] 在演示页面提交表单
   - [ ] 等待几分钟后查看是否显示转化

## ⚠️ 常见问题

如果某些检查项失败：

### 控制台显示错误
- 检查网络连接
- 确认 Google Ads ID 格式正确
- 检查是否有广告拦截器

### 没有网络请求
- 检查浏览器是否阻止了第三方 Cookie
- 确认 gtag.js 脚本正确加载
- 检查控制台是否有 JavaScript 错误

### Google Ads 后台没有转化数据
- 转化数据可能有延迟（几小时到一天）
- 确认不是在测试模式（测试模式下可能不记录）
- 检查转化标签是否正确

## 快速开始

[添加 SSH key 到你的 GitHub 账户](https://docs.github.com/zh/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account)

```bash
git clone git@github.com:NascentCore/inty.git
cd inty
cursor .
```

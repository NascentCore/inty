# Inty 仓库结构调整说明

为贯彻 `backend/BACKEND_CODE_REORG_PLAN.md`，所有后端相关文档已迁移到 `backend/` 目录，根目录仅保留多端入口。常用入口如下：

- `backend/README.md`：后端整体概览与开发指南
- `backend/AGENTS.md`：跨目录协作规范与约束
- `backend/TODOS.md`：后端任务索引
- `backend/docs/`：角色卡、语音、部署等专题文档

若需阅读其他子项目（如 `android_app/`、`web_app/`），请进入对应目录查看它们的 `README.md` 或 `AGENTS.md`。

# AI 角色创作方向（AI_CHARS）

## 总览
- 目标：形成可持续的 AI 角色内容资产，支撑展示、分享与互动。
- 角色类型：电影美人（经典文学改编电影角色/场景）、动漫形象（经典文学改编动漫角色）、奇幻飘渺（经典文学角色）。
- 性别覆盖：包含男性与女性角色。
- 输出形态：角色设定卡 + 关键画面 + 短片片段 + 角色文案/台词。
- 演绎核心：通过预设的经典文学作品清单进行角色演绎与呈现。
- 内容原则：所有角色复刻自原创经典文学作品中的人物，严格遵循原著设定与故事背景。
- 素材要求：仅使用授权原作或授权改编作品素材，不做二创。
- 电影美人详细说明见 [MOVIE_BEAUTY.md](./MOVIE_BEAUTY.md)。

## 方向二：动漫形象（经典文学改编动漫）

### 一句话描述
- 动漫形象：基于经典文学改编的动漫作品角色进行展示，以原著设定为准；风格可参考草薙素子式冷静与强意志气质，仅使用授权素材，不做二创。

### 目标与价值
- 形成稳定的动漫角色资产池，支撑展示与内容运营。
- 满足二次元与科幻爱好者对角色设定、世界观与视觉风格的偏好。
- 为后续角色运营与内容推荐提供统一素材基础。

### 目标用户
- 动漫、赛博朋克、科幻题材爱好者。
- 角色设定控、插画/模型内容消费者。
- 愿意收藏与分享原作角色内容的用户。

### 核心体验流程
1. 进入「动漫形象」专题页，浏览角色卡片与风格标签。
2. 进入详情页，查看角色设定（背景、性格、能力、口癖）。
3. 观看短片或关键画面，理解角色气质与世界观。
4. 分享角色卡片。

### 功能范围（MVP）
- 角色列表页 + 详情页。
- 角色设定卡：原著出典、版本/译本、角色背景、性格、口吻、视觉元素、世界观标签。
- 视觉内容：短片 1 条 + 关键画面 3 张。
- 标签体系：题材、阵营、职业、风格、世界观。
- 分享：生成角色卡片（图 + 简介 + 标签）。

### 非范围（MVP 不做）
- 大型剧情线与多分支互动体验。
- 实时生成动画与大规模语音合成。
- 二创内容生产与高复杂度商业化订阅体系。

### 内容与素材策略
- 授权优先：仅使用原作授权素材，记录授权来源与到期时间。
- 作品清单：以预设经典文学作品清单为范围，并标注原著出处。
- 设定遵循：严格沿用原著的形象设定与故事背景，改编差异需注明。
- 一致产出：每个角色固定输出“设定卡 + 短片 + 关键画面”。

### 合规与风险
- 版权风险：必须建立素材来源台账，确保授权范围与有效期清晰。
- 视觉风险：避免露骨或敏感要素，确保内容审核通过。
- 误导风险：避免暗示与既有作品存在未授权的官方合作。

### 成功指标（初期）
- 角色卡片点击率与停留时长。
- 角色收藏率与分享率。
- 进入互动/共创入口的转化率。
- 7 日回访率。

### 里程碑建议
- Phase 0：确定授权清单与 10-20 个角色池。
- Phase 1：MVP 上线（列表页 + 详情页 + 分享）。
- Phase 2：扩充授权素材与专题集合规模。

### 开放问题
- 角色命名与设定审核流程如何标准化？
- 是否与现有聊天角色体系打通？

## 方向三：奇幻飘渺（奇幻文学角色）

### 一句话描述
- 奇幻飘渺：基于经典奇幻文学作品的角色形象与世界观进行展示，以原著设定为准，仅使用授权素材，不做二创。

### 目标与价值
- 形成奇幻文学角色资产池，支撑展示与内容运营。
- 满足奇幻文学与志怪题材爱好者对角色设定与世界观的偏好。
- 为后续角色运营与内容推荐提供统一素材基础。
- 示例参考（非穷举）：指环王中的 Galadriel、Arwen、Eowyn；聊斋中的聂小倩等。

### 目标用户
- 奇幻文学读者与经典文学爱好者。
- 喜欢古典志怪、史诗奇幻题材的内容消费者。
- 愿意收藏与分享原作角色内容的用户。

### 核心体验流程
1. 进入「奇幻飘渺」专题页，浏览角色卡片与题材标签。
2. 进入详情页，查看角色设定（出典、背景、能力、关系网）。
3. 观看短片或关键画面，理解角色气质与世界观。
4. 分享角色卡片。

### 功能范围（MVP）
- 角色列表页 + 详情页。
- 角色设定卡：出典作品、版本/译本、角色背景、关系、关键事件。
- 视觉内容：授权短片 1 条 + 关键画面 3 张。
- 标签体系：题材、阵营、物种/族群、世界观、时代背景。
- 分享：生成角色卡片（图 + 简介 + 标签）。

### 非范围（MVP 不做）
- 大型剧情线与多分支互动体验。
- 实时生成动画与大规模语音合成。
- 二创内容生产与高复杂度商业化订阅体系。

### 内容与素材策略
- 授权优先：仅使用原作授权素材，记录授权来源与到期时间。
- 作品清单：以预设经典文学作品清单为范围，并标注原著出处。
- 设定遵循：严格沿用原著的形象设定与故事背景，改编差异需注明。
- 版本明确：若存在多版本/多改编，以授权版本为准并标注来源。
- 一致产出：每个角色固定输出“设定卡 + 短片 + 关键画面”。

- 文化风险：涉及宗教、历史、民俗题材时需审慎处理表述。

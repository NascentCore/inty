# 中国 AI 大模型泛消费初创企业融资研究（公开来源）

本文档落实研究计划：纳入标准、公开网页层工商核对、融资轮次与引用、投资机构官网链接、总表。不声称已穷尽中国境内所有符合条件的主体；全量需 IT 桔子 / 企查查导出及工商股权变更交叉验证。

## 1. 已冻结的纳入标准

- 运营或研发重心在中国大陆；已知则写出工商全称。
- 产品形态为面向 C 端的 AI 陪伴 / 情感 / 娱乐 / 游戏陪玩类应用，或消费硬件上以 LLM / 多模态基模为核心体验（非纯规则聊天）。
- **成立日期 >= 2023-01-01**（以工商 `成立日期` 为准，不能用报道日期代替）。
- 排除：无 C 端产品的纯游戏 AIGC 中间件；成立早于 2023 即使 2023 年后才融资也排除。

## 7. 后续补齐「可审计全量」的步骤

- 对「重庆无限星网络科技」「杭州露米」「超级崽崽」运营主体做工商导出，确认 **成立日期** 后再做硬筛选。
- 用 IT 桔子 / 睿兽按标签导出后人工筛：是否 LLM 核心体验、是否 C 端泛消费。
- 对每一轮融资尽量核对 **投资人变更** 工商附件。

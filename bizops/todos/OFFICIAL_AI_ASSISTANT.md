## 概述
- 将底部中间的 **Create** tab 替换为 **IntelliMate** 官方助手入口。
- 点击入口进入官方助手的专属聊天页，首屏风格参考 Gemini 的欢迎页。

## 入口与导航
- 底部 Tab 图标使用应用官方 icon。
- 入口点击后导航到官方 IntelliMate 角色聊天页：
  - agentId 使用官方 IntelliMate 常量。
  - 进入时不自动聚焦输入框，保持欢迎页完整展示。
  - fromPage 记录为 `official_assistant_tab`，便于埋点区分来源。

## 欢迎页结构（无历史对话时显示）
- 顶部问候语 + 副标题（示例：`Hi` / `Where should we start?`）。
- 右侧显示应用 icon。
- 下方展示多枚圆角快捷入口（Chip 风格）。

## 快捷入口与交互
- 快捷入口用于**预填提示词**，点击即把文案写入输入框并聚焦。
- 当前提供的快捷入口：
  - Create a character
  - Explore characters
  - Feature feedback

## 显示条件
仅在以下条件同时满足时展示欢迎页：
- 当前聊天为 IntelliMate 官方角色；
- 聊天记录中没有真实对话消息（仅开场白/系统消息视为无对话）。

## 设计约束
- UI 尺寸与间距统一使用 `UiConfigs` 中的配置项。
- 文案使用 `strings.xml` 资源，避免硬编码。

## 【备选设计】多角色设计（为不同类别功能设计不同的角色）

根据最新信息，官方小助手目前拥有以下功能：

**通知与维护功能**

- 提供系统通知和维护信息。
- 角色名为 Aura，形象为简洁现代风格的 UI 图标或佩戴透明耳机的女性形象。
- 推送场景：计划中的服务器维护、App 版本强制更新、法律/隐私政策变动通知、用户账号异常活动警告。
- 以高效、专业、中立的形象，使用简洁结构化的对话风格。

**功能引导与教学功能**

- 引导用户探索平台功能。
- 角色名为 Joule，形象为充满活力的青年男性或中性形象。
- 推送场景：新功能上线后的引导、低使用率但高价值功能的探索指导。
- 以热情、好奇、乐于助人的性格，使用互动性强的对话风格。

**市场活动与促销功能**

- 推广平台的付费内容和活动。
- 角色名为 Celeste，形象为优雅、时尚的女性形象。
- 推送场景：节日限时付费礼包促销、新角色的首次付费解锁推广、订阅优惠或续费提醒。
- 以迷人、外向的性格，使用强调稀缺性和专属感的对话风格。

**探索已有角色功能**

- 提供角色探索页面（Explore 页面），让用户浏览和了解平台上的各类角色。
- 支持点赞功能，用户可以点赞自己喜欢的角色。
- 角色详情页提供角色信息展示。
- 支持角色排序和分类浏览。

官方小助手的设计理念是提供统一的用户体验标准，让用户能够便捷地获取平台信息、了解功能和参与活动，同时将不同类型的信息以不同角色形象呈现，提高用户体验和参与度。

### 点评

**优点**

- **心智与场景对齐**：通知/维护用 Aura（专业、中立）、功能引导用 Joule（活力、教学）、促销用 Celeste（外向、稀缺感），按场景拆角色比一个形象包办所有事更清晰，利于后续 A/B 或调人设。
- **降低「官方感」与打扰感**：维护/法律/账号安全用独立形象，与主聊天角色分开，用户易区分「严肃通知」与「陪伴」；促销有专属人设，避免主陪伴角色变成「总在推销」，利于保护主关系信任。
- **扩展清晰**：新类别（如客服、活动玩法）可加新角色，不必塞进现有人设。

**劣势与风险**

- **与前半部分「单一入口」不一致**：前文为单 Tab → 单官方助手聊天页、单 agentId；多角色段未写清 Aura/Joule/Celeste 是仅用于推送/触达形象，还是对应应用内多个官方助手会话。需明确「单 agent、多触达形象」或「多 agent、多会话」。
- **「探索已有角色」不是角色、是页面**：探索/点赞/排序/详情是 Explore 页面能力，与 Aura/Joule/Celeste 并列易混淆；建议单独归为「入口与页面能力」，与多角色设计区分。
- **认知与实现成本**：用户需记多个人设；实现上多套人设、提示词、推送路由与落地页，成本与测试量上升。
- **跨场景统一感**：用户从 Aura 维护通知点进、再从 Celeste 促销点进，看到的是同一对话还是两个对话？若为两个则官方助手碎片化；若为一个则多角色主要体现于推送文案/头像，需在文档中写明规则。

**建议（文档层面）**

1. 明确多角色作用域：仅推送/落地页形象，还是应用内多会话；若应用内仍为单会话，写清「单 agent，多触达形象」。
2. 将「探索已有角色」从多角色列表拆出，单独列为「入口与页面能力」。
3. 与 [2026_Q1_MILESTONES.md](2026_Q1_MILESTONES.md) 衔接：若晨午晚仪式/挚爱馆/人生线由官方形象触达，注明由哪一角色（或统一 IntelliMate）承接。

# 智能体模式角色（Agent Mode Role）PRD

## 1. 背景
当前角色仅能进行“单次回复”，无法在一次用户请求中完成多步动作或工具调用。
用户期望更贴近常见 chatbot 的“智能体模式”：例如用户说“send a photo”，角色应主动触发图片生成能力，并发送基于角色形象的图片作为结果。

现有系统已具备“消息生图”能力，但主要依赖显式按钮或单次操作触发。需要将其扩展为角色可自主决定并调用工具的智能体流程。

## 2. 目标
- 让角色具备“智能体模式”，能够多步规划并调用工具完成任务。
- 支持自然语言触发“发照片”等能力，生成符合角色外观的一致性图片。
- 保持现有聊天体验与订阅限额逻辑一致，避免破坏性改动。

## 3. 非目标
- 不实现开放式自动化代理（如跨 App 操作、系统级自动化）。
- 不引入新的外部依赖或模型供应商（先复用现有生图链路）。
- 不在本阶段改变既有的订阅计费与限额策略。

## 4. 需求范围

### 4.1 功能范围（In）
1. **Agent Mode 开关**
   - 角色级配置：开启智能体模式后，该角色允许多步工具调用。
   - 默认关闭，仅对指定角色或灰度用户开放。

2. **智能体执行循环（Agent Runner）**
   - 根据用户输入进行“计划 → 工具调用 → 结果整合 → 回复”的多步流程。
   - 支持最大步数、最大执行时长、超时回退策略。

3. **工具支持（第一阶段）**
   - **图片生成工具**：基于角色参考图生成图片并返回给用户。
   - 复用现有消息生图服务与提示词模板（入口见 `app/services/image_generation_service.py`、`app/core/agent/prompts.py`）。

4. **用户体验**
   - 在聊天中显示“智能体执行中”状态。
   - 工具执行成功后以图片消息或带图片的回复形式展示。

### 4.2 功能范围（Out）
- 复杂外部工具（网页搜索、日程管理、第三方 API 自动调用）。
- 自主任务（agent 在无用户输入时自动行动）。
- 多智能体协作或角色间转交。

## 5. 核心流程

### 5.1 触发
用户自然语言输入触发智能体模式。例如：
- “send a photo”
- “给我看一张你现在的样子”

### 5.2 执行步骤（简化）
1. **判断模式**：若角色开启 Agent Mode，则进入智能体流程。
2. **意图解析**：识别是否需要工具（图片生成）。
3. **工具调用**：调用消息生图服务，基于角色参考图生成图片。
4. **结果返回**：发送图片消息 + 文本说明（可选）。

## 6. 数据与配置

### 6.1 角色配置（示例）
```json
{
  "extensions": {
    "agent_mode": {
      "enabled": true,
      "allowed_tools": ["image_generation"],
      "max_steps": 4,
      "max_runtime_seconds": 12
    }
  }
}
```

### 6.2 消息结构（示意）
```json
{
  "message_type": "image",
  "content": "Here is a photo.",
  "attachments": [
    {
      "type": "generated_image",
      "url": "gs://bucket/path",
      "width": 1024,
      "height": 1024
    }
  ],
  "tool_trace": [
    {
      "tool": "image_generation",
      "status": "success",
      "latency_ms": 4200
    }
  ]
}
```

## 7. API 与服务改动（建议）

### 7.1 Chat 接口扩展
- 在现有聊天接口中新增 `mode: "agent"` 或 `agent_mode: true` 选项。
- 允许返回工具事件（如 SSE/Streaming）：
  - `tool_call`（开始执行）
  - `tool_result`（执行结果）
  - `final_message`（最终回复）

### 7.2 服务层扩展
- 新增 `agent_runner` 负责：
  - 工具选择与调用
  - 步数与超时控制
  - 失败回退（返回文本提示或请求澄清）

## 8. 风险与对策

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 工具调用失败导致体验中断 | 用户流失 | 回退为文本说明 + 可重试入口 |
| 智能体循环过长 | 延迟升高 | 最大步数与超时限制 |
| 生图触发过多 | 成本上涨 | 沿用订阅限额与频控策略 |

## 9. 指标与埋点
- `agent_mode_enabled`：角色启用率
- `agent_mode_request`：用户触发次数
- `agent_tool_image_call` / `agent_tool_image_success`
- `agent_mode_fallback_text`：工具失败后回退次数
- 平均响应时长、图片生成时长

## 10. 里程碑
1. **MVP（内部灰度）**
   - Agent Mode 开关
   - 图片生成工具接入
2. **公开灰度**
   - 流式状态展示与错误回退
3. **全量发布**
   - 复盘指标与成本后推广

## 11. 验收标准
- 当用户输入“send a photo”时，启用 Agent Mode 的角色能生成并发送一张基于角色形象的图片。
- 工具调用失败时，用户收到清晰的文本说明与可重试提示。
- 工具调用与响应耗时在配置的超时范围内，超时后安全回退。

# 角色专区管理（Web UI）

## 1. 适用范围

本文档用于运营同学在 Evaluation Web UI 中完成角色专区配置，不涉及 API 或脚本操作。

## 2. 前置条件

- 已具备可访问 Evaluation 的管理员账号/API Key
- 目标角色已在 dev 环境可检索
- 已确认专区主题、描述、可见性与角色顺序

## 3. 操作步骤（Web UI）

1. 进入 Evaluation 控制台，打开 **角色专区管理** 页面。  
2. 点击 **创建专区**，填写：
   - 名称（Theme Name）
   - 描述（Theme Description）
   - 背景图 URL（可选）
   - 可见性（PRIMARY / SECONDARY / HIDDEN）
3. 保存后进入专区详情，点击 **添加角色**。  
4. 通过搜索选择角色，逐个加入专区。  
5. 使用拖拽或上下排序调整角色顺序。  
6. 点击保存并刷新页面，确认角色顺序与数量正确。  
7. 在 App 端验证专区是否显示、文案是否正确、顺序是否一致。
